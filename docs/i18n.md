# i18n 设计

Agent 提示词模板以英文为唯一编译正文。machine ID、变量名、tags、capabilities、rights、maturity、路径和 schema 均使用稳定英文。

中文承担两类人类界面职责：`solution.json.locales.zh-CN` 保存标题、摘要、用法和搜索别名；`docs/template-zh-CN.md` 保存与英文正文对应的人工审阅译文。两者都不能被误认为中文可编译模板。

翻译必须保持输入合同、限制、输出结构、安全边界和失败条件等价。英文正文变化后，中文审阅译文需要重新核对；自动翻译只能标记为待审草稿。

TemplateContract 的 input name、type、enum、permission 和 schema 不随显示语言翻译。labels 与 descriptions 可以同时提供英文和中文，让中文用户在填写英文模板时仍能看到自然的中文说明。

变量值和最终产物可以使用任意业务语言。模板 locale 只描述指令骨架，不替代 `output_language`、`dialogue_language` 或其他内容语言字段。
