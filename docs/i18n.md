# i18n 设计

`zh-CN` 是 source locale，`en` 是首个同步适配。machine IDs、tags、capabilities、rights、maturity、路径和 schema 不翻译。

英文不是逐字翻译，而是保持输入契约、限制、输出结构和安全边界等价的适配。中文正文发生语义变化后，英文必须重新评审；在 freshness 机制完整前，仓库 release review 通过 Git diff 和 body digest识别变化。

不得把自动翻译直接标记为 reviewed 或 mature。缺少 reviewed 英文时，消费者应明确 fallback 到 `zh-CN`，而不是声称英语版本可用。

TemplateContract 的 input name、type、enum、permission 和 schema 保持英文稳定值，不随 locale 翻译。zh-CN 是 source contract；en sidecar 的约束必须等价，并同时保留 reviewed `zh-CN` 与 `en` labels/descriptions，使中文用户选择英文模板时仍能获得中文填空指引。
