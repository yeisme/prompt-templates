# 视觉探索商业化试点

首批用户是已经使用 Agent 的中文内容创作者。销售假设是经过验证、能解释取舍并可复用的方法值得购买；目前尚无真实买家证据。

免费包完成一次三方向探索，付费候选提供需求整理、探索、选择、精修、迁移与修复。付费正文保留于独立本地私有库，公开站点只有交付说明。90 天修复和文档更新不包含无限定制，价格、交易与最终授权尚待核验。

## 图片评测准则

普通提示词与模板路径使用相同模型、比例与总尝试预算，包含失败，不能只挑成功图。记录精确模板引用、模型、执行日期、候选全集、选择理由、人工编辑、使用权利与限制。主观偏好和约束遵循分别评估。无法完成某项时保留待实测状态，不承诺结果更好或节省比例。

## 四周实验

每周投入 5–10 小时：第一周完成内容和流程，第二周获准后实测案例，第三周展示与指南，第四周由用户招募 5 人。目标为 3 人独立复用、2 笔真实购买，是扩张信号而不是市场成立证明。

每个包持续记录制作、评测、维护、支持工时及复用反馈。记录由 owner CLI/application service 管理，不把用户信息写进公开 Markdown 表格。打不开或不会用先修流程，能用不购买检验价值和报价，售后过重收紧支持边界。多类型目录保留，不先承诺大量上新。
