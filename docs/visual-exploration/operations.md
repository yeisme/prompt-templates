# 视觉探索：支持范围与评测方法

视觉探索入门包为免费 beta，当前成熟度为 `exploratory`。它提供需求整理、三方向比较、独立提示词和复用检查；图片效果及独立用户试用尚待验证。

## 支持场景

| 场景 | 输入与产物 | 检查重点 |
| --- | --- | --- |
| 产品宣传 | 产品描述、方向说明与独立提示词 | 保留主体和材质，不添加未提供的产品承诺 |
| 活动视觉 | 活动需求与方向比较 | 不编造时间、地点、主办方或票价 |
| 内容封面 | 内容主题、构图方向与标题空间 | 信息层级清楚，不添加未要求的文字 |

三个场景均为探索性支持。使用方式见 [入门指南](quickstart.md)。

## 图片评测方法

比较普通提示词和模板效果时，应使用相同模型、比例和总尝试预算，保留失败结果，避免只展示成功图片。记录模板版本、模型、执行日期、选择理由、人工修改和素材许可。

主观偏好与约束遵循应分别评估。跨模型精修需要注明模型切换，不能把全部变化归因于模板。未完成真实生成、编辑和复用验证前，不声明模型已获正式支持，也不承诺效果提升或节省比例。

公开案例应使用可公开的素材与脱敏说明。用户私有资料、会话和运行记录不属于公开案例内容。

## 更新与费用

免费 beta 不承诺固定更新期或人工定制。模板费用与模型调用费用分别计算，具体使用权限以包内许可为准。付费方案尚未开放销售，本页不构成付费支持或更新期限承诺。
