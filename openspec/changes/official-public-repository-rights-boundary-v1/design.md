## 设计

仓库继续公开，便于 Agent 搜索、inspect、同步和读取公共合成 example。权限真源仍是 CLI 生成的 `solution.json` 与 template contract，不增加一个覆盖所有内容的根 LICENSE。

`RIGHTS.md` 只解释边界，不授予新权限。上游 Skill、Remotion、音频、字体、截图和用户产品资料分别服从自己的许可与确认记录。Template Registry 导出的 portable package 也不能扩大来源权限。

## 兼容与回滚

这是文档和治理修复，不改变机器合同。若后续决定采用统一内容许可，应建立新的逐 solution 迁移和版本方案；回滚本变更只会恢复旧说明，不影响 catalog 数据。
