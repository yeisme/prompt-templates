# 视觉探索商业化内容试点

## Why
已有模板目录缺少面向首次使用者的完整视觉探索练习、复用演练和清晰的销售证据边界。用户已确认中文 Agent 创作者、免费完整包与付费探索包、90 天更新和四周验证方向。

## What Changes
- 新增英文可编译的免费三方向探索 beta 包及中文审阅、案例与使用说明。
- 在独立本地私有内容仓准备付费候选包，不进入公开目录。
- 提供可重放的 authoring 与 provider-free 编译、导出、复用验证。
- 补充运营与案例评测指南，不把待实测内容标为成熟。

## Capabilities
### New Capabilities
- `visual-exploration-starter`: 发现、编译、导出与复用视觉探索方案。

## Impact
内容归本仓，消费指南归 Template Registry，展示归独立网页。保持已有 exact refs。真实出图、收费、发布及真实用户反馈为后续外部阶段。
