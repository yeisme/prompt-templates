# Yeisme Official Prompt Solutions

This repository is the Chinese-first official catalog of reusable prompt solution packages. Discovery is organized around user jobs and target artifacts instead of model or provider names.

Chinese (`zh-CN`) is the source locale. English (`en`) is the first reviewed adaptation. Stable IDs, tags, capabilities, rights values, schema keys, and `promptrepo://` references remain English.

Use a Yeisme domain CLI such as Sonora to add, synchronize, search, resolve, and stage solutions. Structured repository metadata is generated by the Template Registry maintainer commands and must not be edited by hand.

The initial 12 solutions are marked `exploratory`. Their catalog structure, bilingual contracts, and digests are verified, but official ownership does not imply production validation. Each solution is promoted to `first-support` only after fixture execution, human review, and known-failure evidence.
