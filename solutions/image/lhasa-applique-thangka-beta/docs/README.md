## 失败与恢复
- 地方差异丢失：退回本条地区与社区范围，不借其他条目填空。
- 正式术语被改为神秘标签：恢复正式名称，把氛围词放在创作描述层。
- 尊像比例、手印、法器、供奉和开光语境须核验；参考缺失时不自由再设计，不声称复刻真迹或已获宗教许可。
- 权限或来源不明：保留待核验状态，先用材料／过程研究，不冒充纪实或真迹。
