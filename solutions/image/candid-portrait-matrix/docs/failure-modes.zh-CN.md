# 失败模式：真实生活摄影抓拍写真（随机矩阵）

| 失败模式 | 表现 | 处理 |
| --- | --- | --- |
| 摆拍感回潮 | 人物正对镜头微笑、姿势端正 | 检查 `expression`/`moment` 是否被弱化；在负向中重申不要直视镜头 |
| 前景不遮挡 | 前景元素完整清晰展示 | 确认 Prompt 保留「前景必须自然侵入画面」句；换更强势的前景取值 |
| 荒谬组合 | 车厢机位出现在荷塘 | 组合未过兼容约束；必须经采样器生成，不要手工拼 |
| 色彩溢出 | 画面出现 5+ 高饱和色块 | 检查 `palette` 绑定；负向加「避免五颜六色」 |
| 影楼化 | 均匀布光、磨皮、纯色背景 | 检查 `light`/`state` 是否被改写成棚拍词汇 |
| 批次撞车 | 同批两张画面观感雷同 | 用 manifest tags 对比四维；加 exclude 重采 |
