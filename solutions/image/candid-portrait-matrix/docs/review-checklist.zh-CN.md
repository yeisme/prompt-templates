# 评审清单：真实生活摄影抓拍写真（随机矩阵）

- [ ] 前景自然侵入画面并形成明显遮挡，未完整陈列所有元素。
- [ ] 机位/构图/前景与场景类别兼容（荷叶机位→荷塘类、车厢机位→车内类、窗边光线→室内窗类）。
- [ ] 画面主色块不超过 4 个，无五颜六色。
- [ ] 人物未直视镜头（除非 expression 显式要求），无标准网红摆拍感。
- [ ] 人物非常规居中，景别与焦段匹配（远距离压缩↔长焦、广角畸变↔24/28mm）。
- [ ] 皮肤质感自然，无过度磨皮与塑料皮肤。
- [ ] 同批次 scene/camera/composition/foreground 四维不重复，combo 哈希唯一。
- [ ] 无影楼感、无棚拍感、无复杂道具与杂乱背景。
