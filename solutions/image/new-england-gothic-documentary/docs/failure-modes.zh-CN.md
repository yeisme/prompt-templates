# 失败模式：新英格兰哥特纪实摄影风格层

| 失败模式 | 表现 | 处理 |
| --- | --- | --- |
| 戏剧化回潮 | 大片感、动作场面、英雄姿态 | 重申「孤独而非戏剧化、克制构图」；检查负向 |
| 夜生活/节日感混入 | 霓虹、人群、派对、酒吧灯 | 负向已含 crowd/festival/nightlife/neon；重申空旷与黑暗 |
| 摆拍感 | 人物正对镜头、对视、微笑 | 重申「mostly from behind or in profile、no eye contact」 |
| 主体过大、构图过满 | 人物占满画面、背景杂乱 | 重申「subjects relatively small in frame + large areas of empty ground and darkness」 |
| 明信片化 | 金色夕照、旅游宣传光泽 | 重申 pre-dawn/夜间 + practical available light |
| HDR/高反差回潮 | 高对比、过度锐化、光泽修饰 | 检查负向 HDR/high contrast/oversaturation 是否完整 |
| 哥特被读成恐怖 | 超自然元素、恐怖片雾效、惊悚构图 | 负向已含 horror clichés/fog machine；重申 quiet melancholy |
| 风格化插画风 | 动漫、绘画、3D 渲染质感 | 检查负向 anime/painting/3D render；重申 photorealistic |
