## 失败与恢复

- 输入缺失：先补齐字段，不用猜测完成会话。
- 风格只有颜色差别：重写构图、光线/图形处理和信息层级差异。
- 比例不受当前环境支持：由执行工具报告，不悄悄裁切。
- 主体或事实漂移：优先恢复硬约束，再调整风格。
- 未选方向：保留候选，不能由 Agent 自行代签用户确认。
- 对比证据缺失：保留“未实测”状态，不能用概念图替代效果证据。

## 发布前实测

每个主题比较普通提示词与模板路径，使用同一模型、相同比例和相同总尝试预算。保留候选全集、版本、选中理由、人工修改与失败。主观偏好与约束遵循分开记录。模型实际运行、费用和资产接纳由 Eikona 管理。
