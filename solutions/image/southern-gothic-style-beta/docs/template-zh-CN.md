# 南部哥特风格模板

一个可复用的风格层：美国南方的衰败、宗教、暴力、压抑与怪诞之美——优雅与腐烂并存。它不是传统欧洲哥特式：没有古堡、没有吸血鬼；真正令人不安的是家庭、社会和人本身，而非超自然怪物。每张图只换场景、人物与可选主题句；所有风格段固定。渲染前绑定全部变量；渲染结果即最终提示词正文，不再改写。

南部哥特氛围，优雅的腐烂：旧南方的褪色荣光沉入潮湿的腐朽；曾经辉煌、如今衰败的世界——破败庄园、凋零农场、小镇教堂、墓地、废弃汽车、褪色墙纸与残破家具；环境看似宁静，危险、秘密与死亡感却从一切缝隙里渗出。

自然繁盛到近乎腐败：西班牙苔藓垂挂枯树、藤蔓吞没木墙、沼泽与湿地、棉田、茂密的南方树林、昆虫、乌鸦、鹿骨与野花；潮湿的夏日雾霭笼罩乡野孤寂——小镇、河湾沼泽、维多利亚式农宅与木板小屋。

人物的怪诞之美：孤僻者、传教士、寡妇、旧南方家族、流浪者、怪人、儿童与边缘人物，带着心理创伤与道德矛盾；庄重与畸形并存，肃穆而不安，既不美化也不嘲弄。

低饱和土地色系：褪色棕、灰绿、脏白、暗红、烟草黄、泥土色；像旧照片或被阳光晒褪色的胶片，颜色被炎热与时间抽干。

压抑的南方光线：闷热强烈的日光、昏暗室内、烛光、黄昏、暴风雨前的阴沉天空；强烈明暗反差，户外的灼热眩光对照阴影房间，光线揭示衰败而非讨好画面。

时间与腐烂的质感：旧木头、锈铁、灰尘、汗水、泥土、裂纹、霉斑、蕾丝、旧圣经与古董；一切带着岁月侵蚀，可触、被生活磨过——不干净、不崭新。

## 自检

- 场景、人物与主题句换入；所有风格段未动。
- 优雅与腐烂并存：褪色荣光、繁茂腐朽的自然、庄重怪诞的人物、低饱和土地色、强明暗反差的压抑光线。
- 不安来自人与道德——家族、信仰、贫困、暴力——而非超自然怪物或欧洲哥特陈词；无 glamour、无糖果色、无干净现代表面。
