| 真实信仰被写成"邪教/诅咒部落" | 敏感性门槛未执行 | 退回空间/光线/材料/历史记忆描述；条目转 Review | 加"免责声明"后照发恐怖化 prompt |
| 奴隶制/刑罚史被浪漫化 | 门槛覆盖不足 | 删除庄园美化/鬼屋乐园化措辞；引入制度史事实（convict sites、劳动史） | 用"氛围需要"辩护美化 |
| 一行堆五六个风格标签 | 分配规则违规 | 收敛为一个 primary + ≤2 secondary，其余写进 mixed 建议 | 保留"全都要"的标签堆 |
| Prompt 正文架空本地逻辑（西湖写成欧洲 Gothic） | 风格标签压过地方逻辑 | 地方审美优先（中国山水构图/波斯园林几何/Indo-Gothic 融合身份），风格只作视觉转译声明 | 反向用西方模板覆盖地方复杂性 |
| Mixed variant 加了三个以上元素 | 混合变体失控 | 每次混合只加 1–2 个可命名元素 | 把混合写成第二篇正文 |
| confidence 全是 A | 分级通胀 | A 需官方原始来源+学术/地方来源双证；不确定降 B/C | 用 D 级 aesthetic 站支撑 A 级结论 |
| 场景事实来自旅游博客 | 来源分级违规 | 换 S/A/A- 级来源重写 scene_facts；D 级只留作关键词发现 | 直接引用商业博客当事实 |
