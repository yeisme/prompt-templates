# 失败模式：ICONIC LANDMARK SERIES 城市地标海报

| 失败模式 | 表现 | 处理 |
| --- | --- | --- |
| 地标比例错误 | 钟楼弯曲、重复塔楼、钟面缺失 | 检查 hero_identity/hero_placement 绑定；城市负面词补充对应条目 |
| 上下不对应 | 下半矢量画了别的建筑 | 重申「上下两半必须表现同一组地标」；核对 landmarks_line |
| 卡通化 | 粗描边、高饱和、Q 版比例 | 检查 feel/hero_simplification 是否保留「档案感」「无粗黑描边」 |
| 排版缺槽位 | 坐标或 EST 缺失、乱码 | 对照五槽位清单逐项核对；负向含文字乱码 |
| 彩蛋抢戏 | 彩蛋面积过大或具象 | 重申 ≤ 1% 面积上限 |
| 系列漂移 | 某城市分割比例或风格栈不同 | 变体不许覆盖视觉系统字段；用 palette.accent tags 做跨城审查 |
| 远景抢主体 | 现代建筑或相邻地标过强 | 检查 background 弱化绑定；城市负面词加入干扰地标 |
