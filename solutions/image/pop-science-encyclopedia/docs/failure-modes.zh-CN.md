# 失败模式（科普百科图鉴）

1. **中文乱码 / 伪汉字**：高信息密度 + 大量图内文字是最主要失败面。出现后降低模块数上限重跑，或接受版式意图、后期人工排版覆盖正文。
2. **退化为单主体大海报**：模型丢掉模块化结构只画主体大图。检查渲染结果是否完整包含模块清单段落；必要时在编译侧加强 "modular information cards" 段。
3. **商业广告感渗入**：出现促销角标、价格、购买按钮、夸张营销文案。确认 negative 约束未被改写；评审时直接 reject。
4. **信息过载无呼吸感**：模块挤满画面、无留白。减少模块数到 6 个、减少每模块条目到 3 条。
5. **主视觉科学失真**：动植物结构、机械剖面画错。本模板不保证科学准确性，发布前需领域核对；评分卡内容尤其不能当作真实数据引用。
6. **配色漂移**：背景变高饱和或撞色彩。绑定 `palette_hint` 锁定主色，系列化生产时保持该变量不变。
7. **变量未绑定残留**：渲染结果含 `{{}}` 即编译失败，属预期 fail-closed，不得手工改渲染产物。
