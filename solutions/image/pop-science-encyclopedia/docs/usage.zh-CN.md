# 使用说明（科普百科图鉴）

## 适用场景

单个主题的竖版科普信息图：动植物、食品、机械/产品、人体/生物、建筑、自然现象、知识主题。适合社交媒体科普、系列化知识卡片、公众号配图、短视频封面延展、教育展示。

## 输入变量

| 变量 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| `topic` | 是 | 主题中文名（主标题与主视觉共用） | 中华穿山甲 |
| `english_name` | 是 | 英文名或学名 | Manis pentadactyla |
| `subtitle` | 是 | 图鉴副标题 | 物种观察图鉴 |
| `palette_hint` | 否 | 配色提示短句，自带前导空格；不用则空字符串 | ` ，主色取浅绿与奶白` |

## 编译与执行

- 编译器对未绑定变量和残留 `{{}}` 必须 fail-closed；渲染结果即最终 prompt，不得改写。
- 执行走 Eikona：`eikona generate --model openai/gpt-5.4-image-2 --aspect 3:4 --input <渲染后文件> --agent`，先 `--dry-run` 再真实生成。
- 系列化生产时固定 `subtitle` 与 `palette_hint`，只换 `topic` / `english_name`，保证一套图鉴风格统一。

## 审阅要点

- 图内中文是否可读、有无乱码（本模板最大失败面，见 failure-modes）。
- 模块数是否在 6–10 个、信息是否一行式简短。
- 主视觉占比约 35–45%，无商业广告元素混入。
- 文字准确性必须人工核对，不默认信任生成图内文字。
