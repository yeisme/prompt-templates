# 科普百科图鉴（风格层）

本模板为一个主题生成一张竖版科普百科图鉴页。只需绑定主题变量，其余结构与风格段落保持固定；渲染结果即最终提示词正文，不得改写。图内文字以中文为主、配少量英文模块小标题，模型必须输出可读汉字。

## 主体

{{topic}}（{{english_name}}），以「{{subtitle}}」图鉴页呈现。

## 目标

不是普通海报、广告页或单纯插画，而是具有百科全书、自然观察图鉴、知识卡片、信息可视化、收藏图鉴气质的模块化科普信息图。画面同时具备主视觉吸引力、系统知识组织、局部结构展示、信息模块化与收藏感，像高级科普百科中的独立图鉴页，可用于社交媒体传播、知识科普、系列化内容、教育展示和收藏。

## 整体视觉风格

高级自然历史图鉴 + 现代百科全书页面 + 精品杂志信息设计 + 高质量社交媒体科普信息图。{{palette_hint}}

视觉关键词：clean editorial infographic、premium encyclopedia、scientific illustration、natural history illustration、knowledge card、modular information design、museum guide style、editorial layout、collectible reference card、high information density、elegant educational poster。

竖版构图；浅色干净柔和背景（奶白、米色、灰白、浅绿、浅蓝或按主题适配的低饱和配色）；柔和自然光；极轻阴影；圆角信息卡片；精致细线；小型科学图标；克制装饰；信息丰富但不拥挤；留白充足；明确视觉层级；像真实出版物而非电商广告；避免促销、价格、购买按钮等商业广告风格。

## 主视觉

画面中心或黄金区域展示清晰、美观、有真实质感的 {{topic}}：完整、辨识度高、细节丰富、姿态自然、构图有展示价值，兼顾科学准确性与审美。可采用高端写实插画、自然历史插画、科学绘图或高级摄影插画融合，按主题自动选择。主视觉是整张图鉴的第一焦点。

按主题适配：
- 动物：完整身体、自然姿态、毛发/皮肤/羽毛细节清晰。
- 植物：完整植株、叶片、花、果实、根系或典型结构。
- 食品：完整食物 + 切面 + 原料状态。
- 机械/产品：完整外观 + 半透明结构示意 + 局部拆解。
- 人体/生物：整体位置 + 结构剖面 + 功能示意。
- 建筑：整体外观 + 局部构造 + 平面/剖面辅助。
- 自然现象：主体场景 + 形成过程 + 原理结构。

## 局部放大细节

围绕主视觉设置 3–6 个局部放大窗口（圆形、椭圆、圆角矩形或显微镜式放大框），用细线与主体连接。自动选择最值得观察的特征：外观细节、材质纹理、表面/内部结构、关键器官、工作部件、连接结构、截面、微观结构、独特标志、颜色变化、叶脉、鳞片、毛发、接口、芯片、骨骼、果肉、种子、晶体结构等。每个细节模块包含中文细节名称 + 一句简洁科学说明。

## 标题层级

顶部建立清晰的百科标题体系：

- 主标题：【{{topic}}】
- 英文或学术名称：{{english_name}}
- 副标题：「{{subtitle}}」
- 一句极短知识定位语（按主题自动选择），如「认识结构，理解原理」「从外观到内部结构」「了解它如何生长、运作与适应环境」。避免商业广告语。

## 模块化信息卡片

多个圆角信息模块围绕主体排布。每个模块：小图标 + 中文标题 + 可选英文小标题 + 3–6 条一行式简短信息，层级清晰，避免大段文字。按主题自动选择 6–10 个最合适模块：

1. 基础信息 Basic Profile：名称、学名、别名、类别、产地、发现时间、尺寸、重量、寿命、主要用途、核心特征。
2. 分类信息 Classification：界/门/纲/目/科/属/种，或产品/技术/结构/材料类别。
3. 外观特征 Appearance：颜色、形态、尺寸、纹理、典型标志、结构比例、辨识特点。
4. 核心结构 Structure：内部组成、关键部件、核心机构、分层结构、材料组成。
5. 工作原理 / 形成机制 How It Works：A → B → C → D 简洁流程。
6. 生活习性 / 生态 Habits & Ecology：栖息环境、活动规律、食物、行为、繁殖、适应能力。
7. 生长 / 使用条件 Growth / Usage Conditions：温度、湿度、光照、环境、能源、空间、操作条件。
8. 使用 / 养护建议 Care / Maintenance：养护、保存、使用、日常维护、清洁频率、环境要求。
9. 风险与注意事项 Risks & Precautions：常见风险、错误使用、潜在危害、不适用情况、健康/环境影响；轻量警示图标，不制造恐慌。
10. 优缺点对比 Pros & Cons：左右双栏 ✓ / ×。
11. 适合人群 / 适用场景 Suitable For：适合的人、环境、场景与不适合情况。
12. 健康 / 安全关注 Health & Safety：宠物、食品、人体、植物、户外、设备工具适用。
13. 历史 / 来源 History & Origin：起源、发现、发展、传播、演变；可配小地图或时间线。

## 快速评分卡

一个视觉化 Quick Rating 模块，按主题自动选 4–7 个维度，用 ★ 星级或横向进度条。示例——动物：智力/运动量/亲人度/训练难度/护理需求；植物：养护难度/光照需求/浇水需求/生长速度/观赏价值；食品：营养密度/热量/蛋白质/饱腹感/储存便利度；汽车：性能/舒适度/空间/油耗/可靠性；电子产品：性能/续航/便携性/耐用度/易用性；知识主题：复杂度/实用性/影响范围/理解难度。评分仅为视觉化概括，不伪装成绝对科学数据。

## Top 5 核心亮点

醒目的「Top 5 核心亮点」模块，1–5 编号，每条为加粗核心词 + 一句解释，总结该主题最值得记住的五个知识点。

## 数据可视化

主题适合时加入少量可视化：小地图、分布区域、时间线、生命周期、生长过程、结构剖面、尺寸比例、柱状图、能量/工作流程、温度/速度范围。保持简洁，不做复杂商业报表。

## 小结

底部【小结 / Summary】：3–5 句话说明它是什么、最大特点、为什么值得了解、最需注意什么。语言自然客观有知识感，避免营销宣传。

## 图标与装饰

统一风格小图标（信息、地图、时间、温度、结构、显微镜、叶片、动物、大脑、运动、工具、警告、医疗、家庭、环境、能源、维护）：简约、线性、低饱和、尺寸小，不抢主视觉。

## 版式原则

中央主视觉 + 周围知识模块 + 局部放大 + 评分模块 + Top 5 + 总结，构成「主视觉 + 知识网络」。面积配比约：主视觉 35%–45%，信息模块 45%–55%，装饰 5%–10%。信息密度高但保持呼吸感、网格感、层次感、阅读顺序与模块间视觉联系。

## 文字要求

图内文字以中文为主，配少量英文模块小标题（Basic Profile、Appearance、Structure、Habits、Care Guide、Risks、Quick Rating、Highlights、Summary）。文字科学、简洁、准确、易读；避免无意义文案与广告语言；标题清晰有力量，正文高度可读，不出现乱码。

## 最终质量线

画面呈现高级科普出版物、自然历史图鉴、现代百科全书、收藏卡、科学杂志专题页的综合气质：第一眼看到主体，第二眼阅读知识模块，第三眼愿意探索细节。强调 knowledge organization、modular information、scientific illustration、encyclopedia layout、collectible design、editorial infographic、visual storytelling、information hierarchy。

不要做成：商业广告、促销海报、商品详情页、儿童卡通海报、普通插画、简单文字排版、只有主体的大图海报。

最终要求：high-end、editorial、scientific、informative、collectible、beautiful、high information density but clean、premium encyclopedia infographic、publication-ready、social-media friendly、vertical composition。
