# 失败模式：修仙朦胧风风格层

| 失败模式 | 表现 | 处理 |
| --- | --- | --- |
| 仙气元素堆砌 | 仙鹤、莲花、光效堆满画面 | 回到核心六要素；删除堆砌词 |
| 高饱和回潮 | 霓虹、艳色、强金 | 检查负向是否完整；重申低饱和月白雾金 |
| 摆拍感 | 人物正对镜头凹造型 | 重申「不刻意摆拍、微微回眸、柔和疏离」 |
| 硬光切割 | 死黑阴影、高反差 | 重申逆光/侧逆光 + 柔焦 + 低对比 |
| 服装过繁复 | 首饰堆砌、层叠过度 | 重申「华美但不过度繁复」 |
| 西化混入 | 西式盔甲、欧美魔幻元素 | 负向已有；检查 persona 描述是否引入 |
