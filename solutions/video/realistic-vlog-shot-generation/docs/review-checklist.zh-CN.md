# 评审清单：写实生活记录视频生成

渲染结果投递视频生成模型前，逐项核对：

## 变量与引用

- [ ] 无残留 `{{...}}` 占位符。
- [ ] `character_ref` 若填写，来自已登记资产库，未编造。
- [ ] sensitive 输入未进入日志、事件、证据或结构化输出。

## 时序与结构

- [ ] 序列节拍连续覆盖 0-`duration_s`，无空洞、无重叠。
- [ ] 每拍 1-3 个可观察动作，无内心描写。
- [ ] 每个事件有可拍到的触发源（风、浪、物件交互）。
- [ ] 结尾指令与总时长协调（如硬切黑场时间早于 `duration_s`）。

## 一致性

- [ ] `consistency_lock` 全文保留：身份、服装、发型、比例、配饰全片锁定。
- [ ] `subject_identity` 与 `wardrobe_and_accessories` 在序列节拍中没有被无意改写（如换装、摘配饰）。

## 写实与气质

- [ ] `camera_imperfections` 的不完美质感保留，未被分镜描述修掉。
- [ ] 场景排除项、拍摄禁止项、声音禁止项三节完整保留。
- [ ] 写实约束包含物理、材质、光影、手部与解剖条目。
- [ ] `final_feel` 与序列情绪一致（日常、亲密、不摆拍）。

## 投递匹配

- [ ] 分辨率、画幅、时长与目标模型能力匹配。
- [ ] 按消费方需求决定变量内容语言（骨架为单语言 en）。
