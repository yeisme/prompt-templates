# 写实生活记录视频生成 Prompt（写实 Vlog 镜头）——中文阅读版

> 本文档是 `prompts/main.en.md` 的中文阅读版，仅供人工审阅，**未注册为模板 locale，不进入 catalog 编译**。渲染与投递一律以英文模板为准；变量名与英文模板一一对应。

本模板是一条可直接渲染后投递给视频生成模型的镜头级 Prompt，用于生成「朋友随手拍下的真实片段」气质的写实生活记录视频。消费方在渲染前完成全部变量绑定；渲染结果是最终视频生成 Prompt 正文，不经过二次改写。

## 使用方式

1. 按 companion contract 填写全部 required 变量；有人物资产时填写 `character_ref`（支持 `@uuid` 与 `@image1` 等位置引用）。
2. 可选：填写 `provider_banner` 保留投递平台标识行（如 `Made with Seedance 2.5`），留空则渲染结果不含该行。
3. `sequence_beats` 按「时间线序列」一节的结构编写，连续覆盖 0-`{{duration_s}}` 秒。
4. 渲染后先人工核对「自检清单」，再投递视频生成模型。

## 时间线序列

`{{sequence_beats}}`

序列结构要求：每个节拍包含时间区间与 1-3 个可观察动作；时间区间连续覆盖 0-`{{duration_s}}` 秒，无空洞、无重叠；动作必须是镜头可拍到的外在行为，不写内心描写。

## 写实约束

`{{realism_rules}}`

默认写实约束（未被 `realism_rules` 覆盖时并入）：准确物理，自然的行走、头发、织物、纸张、绳索、海水、光照与阴影，正确的手部与面部表情；禁止形变、物体复制、道具消失、服装漂移与解剖错误。

## 声音设计

`{{audio_design}}`。声音禁止项：`{{audio_exclusions}}`。

## 结尾与整体气质

结尾指令：`{{ending_directive}}`。最终气质：`{{final_feel}}`。

## 全局约束（渲染后必须保留在 Prompt 末尾）

- 一致性锁定全程生效：身份、服装、发型、比例与配饰在任何镜头不得漂移。
- 场景排除项、拍摄禁止项、声音禁止项全程生效，不得只在序列中声明一次。
- 无 UI、字幕、水印、Logo 与品牌露出。
- 所有事件必须有可拍到的触发源；禁止凭空出现的物体与特效。
- 时间线连续覆盖全片；结尾严格按 `{{ending_directive}}` 执行。

## 负面提示词

`{{negative_prompts}}`

默认负面项（未被 `negative_prompts` 覆盖时并入）：精致商业广告感，稳定器/无人机运镜，慢动作，摆拍人群，品牌、地标、广告；形变，物体复制，道具消失，服装变化，解剖错误，多指；音乐，旁白，字幕，标题，Logo，水印；特效光效，凭空出现的物体，无触发源事件。

## 渲染后自检清单

1. 所有变量均已绑定，正文中不存在残留占位符。
2. `character_ref` 若填写，必须来自消费方已登记的资产库，未编造引用。
3. 序列节拍时间区间连续覆盖 0-`{{duration_s}}` 秒，无空洞、无重叠；每拍均为可观察动作。
4. 一致性锁定、写实约束、声音与拍摄禁止项在渲染结果中完整保留。
5. 结尾指令与 `duration_s` 不冲突（如硬切黑场时间早于总时长）。

无法满足时：缺少必填变量或序列无法连续覆盖全片时，停止渲染并列出缺口，不得编造资产引用或跳过一致性锁定。
