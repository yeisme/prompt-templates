# 实例：朋友手持的一日旅行 Vlog（30 秒，城市→海边）

本例展示 `realistic-vlog-shot-generation` 绑定为一条「朋友跟拍的一日旅行」Prompt：清晨从公寓出发，经城市街区与街市，午后抵达海边，黄昏收尾。无 Provider 横幅（`provider_banner` 留空）。

## 结构判断

- 无脚本台词、无 VO、无音乐弧线 → 走纯环境音流。「对镜头简短说话、自然笑」是未编排的现场声，写入 `audio_design`，不需要 `realistic-diary-vlog-generation` 的台词脚本结构。
- 20-27s 出现朋友群像：一致性锁定只约束主角；群像按「真实人群行为」写入 `realism_rules`，不进锁定范围。
- 一天内光线递进（清晨→午后→黄金时刻）写入 `sequence_beats` 的节拍描述与 `realism_rules` 的光照条目。

## 变量绑定

| 变量 | 值 |
| --- | --- |
| `footage_style` | `authentic travel vlog footage, realistic smartphone/mirrorless camera look` |
| `duration_s` / `resolution` / `aspect_ratio` | `30` / `1080p` / `16:9` |
| `scenario_summary` | `同一位女性的一日旅行：清晨离开公寓，穿过城市街区与街市，午后到海边会朋友，黄金时刻收尾` |
| `subject_identity` | `严格继承参考图女性的面部身份、发型、五官与身体比例` |
| `wardrobe_and_accessories` | `继承参考图服装与配饰，加一只小背包；全天不换装` |
| `consistency_lock` | `全片保持她的确切面部身份、发型、五官与身体比例；无面部漂移、无身份变化` |
| `character_ref` | `@image1`（参考图位置引用） |
| `setting_desc` | `真实日常环境：温馨公寓门口、安静的清晨居民区街道、本地小咖啡馆、街市小店、通往海边的公共交通或步行路、海滨小镇与沙滩` |
| `setting_exclusions` | `无品牌、地标、广告、摆拍人群、文字招牌特写` |
| `camera_style` | `亲密朋友全天手持跟拍（手机或微单），像真实个人 vlog 而非商业制作` |
| `camera_imperfections` | `自然手持晃动、随意构图、不完美的人工运镜、偶尔失焦、曝光随光线自然变化` |
| `camera_exclusions` | `无稳定器、无人机、电影化商业质感、戏剧化摆拍、人造转场` |
| `sequence_beats` | 见下方时间线 |
| `realism_rules` | `准确解剖与自然身体力学；真实人群行为（街市路人、海滩朋友）；可信的光照递进（清晨斜光→午后顶光→黄金时刻）；自然风吹头发与衣料；无脚本表演感` |
| `audio_design` | `现场原生声：清晨街道底噪、咖啡馆嘈杂、街市人声、交通声、海风、海浪、朋友谈笑、她对镜头未编排的简短说话与自然笑声` |
| `audio_exclusions` | `无配乐、旁白、罐头音效、字幕、屏幕文字、Logo、水印` |
| `final_feel` | `一段真实的个人旅行记忆：亲密、随意、不完美，像朋友相机里被遗忘却舍不得删的一天` |
| `ending_directive` | `黄金时刻：她坐在海边拿着饮料看日落；镜头缓慢后退揭示沙滩、海浪与平静傍晚，自然结束` |
| `negative_prompts` | `商业广告质感，稳定器/无人机，电影化运镜，戏剧化摆拍，人造转场；面部漂移，身份变化，多余主角，手部畸形，道具消失；文字叠加，字幕，Logo，水印；配乐，旁白，罐头音效` |

## 时间线（`sequence_beats`）

```text
[0-5s 清晨出发] 朋友手持从后方跟拍（轻微晃动）。她背小背包离开公寓，看手机，对镜头微笑，拨头发，开始向外走。清晨阳光，安静居民区街道，路人开始一天。
[5-12s 城市探索] 跟拍穿过本地街道；进小咖啡馆买饮料，对镜头简短说话、自然大笑；穿过街市看小店，随手拍照。相机保持近距离，捕捉即兴瞬间。
[12-20s 抵达海边] 乘公共交通或步行向海边移动；环境从城市街道渐变为海滨小镇；海风拂动头发，她看到海时露出兴奋；跟拍她沿海滩走，捡贝壳、看海浪、与附近的人自然互动。
[20-27s 夏日海滩午后] 她在海滩与朋友会合；众人聊天、大笑、在水边玩；相机在人群间自然移动抓拍；她回头看镜头微笑。
[27-30s 结尾时刻] 黄金时刻日落；她坐在海边拿着饮料看日落；镜头缓慢后退，揭示沙滩、海浪与平静傍晚；自然结束，无黑屏。
```

## 渲染与投递

- 投递时 `@image1` 绑定女主参考图（可用 Eikona 生成的参考图，见 `eikona assets resolve` 流程）。
- 自检重点：一致性锁定只锁主角；光线递进与五拍时间段匹配；「无字幕/Logo/文字」在排除项与负面提示词中重复出现；结尾为缓慢后退自然收束，非黑屏硬切。
