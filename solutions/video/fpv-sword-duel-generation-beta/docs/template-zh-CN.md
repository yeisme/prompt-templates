# 电影级穿越机刀战视频生成 Prompt（双色刀气特效）

本模板渲染后可直接投递视频生成模型，用于生成「双人电影级刀剑对拼」视频：首帧构图锁定、双人物身份锁定、两套一眼可区分且绑定动作的刀气特效、穿越机环绕镜头、可读的攻防逻辑、以及「压制但不击败」的结构弧线。消费方在渲染前完成全部变量绑定；渲染结果是最终 Prompt 正文，不经过二次改写。

与家族内其他模板的边界：无特效、强物理的近身格斗用 `realistic-fight-scene-generation`；蓄力-爆发型大招清屏镜头用 `ai-drama-shot-video-generation`。本模板专攻穿越机环绕的双剑客对拼，视觉重点是刀路绑定的刀气与对拼破坏，不是魔法球或清屏光炮。

## 使用方式

1. 按 companion contract 填写全部 required 变量；`first_frame_ref` 为必填的第 0 秒构图与人物视觉基准（支持 `@uuid` 与 `@image1` 等位置引用）。
2. 可选：`provider_banner` 保留投递平台标识行，留空则省略。
3. `fight_beats` 按「对拼时间线」结构编写，连续覆盖 0-`{{duration_s}}` 秒。第 0 拍必须继承首帧构图 `{{first_frame_hold_s}}` 秒。
4. 渲染后先人工核对「自检清单」，再投递视频生成模型。

## 影像规格与风格

`{{footage_style}}`。品质设定：`{{quality_profile}}`。总时长 `{{duration_s}}` 秒，分辨率 `{{resolution}}`，画幅 `{{aspect_ratio}}`，帧率 `{{frame_rate}}`。场景梗概：`{{scenario_summary}}`。风格参照：`{{style_reference}}`——只继承气质、近身压迫感与镜头语言，不照搬参照作品中的人物、场景与具体镜头。

固定观感：真实摄影质感，次世代光影，PBR 材质，布料、头发、尘土、石块、金属火花都要细致。整体剪辑要像高规格动作演示片：镜头快，但每一刻都能看清谁在进攻、谁在防守。

## 首帧锁定

第 0 秒严格继承 `{{first_frame_ref}}` 作为开场构图，以及双方人物的视觉基准。该构图保持 `{{first_frame_hold_s}}` 秒，随后穿越机立刻从侧面低空绕出。角色 A 在首帧左侧，角色 B 在首帧右侧。开场不得重新摆位、对调左右、改服装，也不得凭空出现第三者。

## 双人物与一致性锁定

角色 A（左侧，压迫方）：`{{fighter_a_identity}}`

角色 A 特效体系：`{{fighter_a_vfx}}`

角色 B（右侧，被压制但不败）：`{{fighter_b_identity}}`

角色 B 特效体系：`{{fighter_b_vfx}}`

格斗风格对比：`{{character_dynamics}}`

一致性锁定（全片不可放宽）：`{{dual_consistency_lock}}`

固定规则：全程不得交换两人身份，不得变脸、改年龄、改发型、改体型、改身高比例、改服装颜色、改鞋子配饰；不得生成第三名参战者。两套特效必须一眼可区分：A 更黑、更狂、更具侵略性；B 更冷、更净、更锐利。刀气是墨风、真空斩纹、裂空气刃，不是魔法球、激光炮或彩虹光。

## 场景与空间连续性

`{{scene_desc}}`

空间布局与行动轴线：`{{scene_layout}}`

光影与材质：`{{lighting_palette}}`

固定规则：全程保持同一处残破街巷 / 庭院，不切换场景。地物位置在所有镜头中保持一致，不得随切镜瞬移。除非穿越机环绕明确展示换位，否则双方始终保持清楚的行动轴线。镜头可以穿梭两人之间、围绕对拼点盘旋，但必须始终看清双方站位，以及谁在进攻、谁在防守。

## 动作原则

`{{action_principles}}`

固定战斗规则：每次重要进攻必须呈现起点、运行路径、接触点和结果；格挡必须真正改变或卸掉这一刀；步法、转髋与刀路保持物理连接。短距踩墙、空中交错、低空爆冲可以出现，但必须可读、落地有重量。禁止隔空挥刀、肢体穿透、瞬移、站桩对峙、长时间正面摆拍。

结构弧线：`{{fight_arc}}`

固定弧线规则：角色 A 始终更主动、更猛烈，保持强压迫。角色 B 实力极强、招式要帅，但在本片中逐渐落入下风，被压制、被逼退、被连段压住节奏——绝不能被击败，不能狼狈崩坏，不能失去风度。结尾胜负未分：A 占上风，B 挡下最后一轮。

环境破坏：`{{environment_destruction}}`

固定破坏规则：破坏要有质量和力量感。地砖、石柱、木梁、旗幡、尘土、碎石应对真实对拼与刀风作出反应，不是装饰性闪光。碎片沿冲击方向飞出。

## 刀气特效绑定

`{{vfx_binding_rules}}`

对拼撕裂：`{{clash_vfx}}`

固定特效规则：每一次重要出刀都要有高级刀气，且必须跟随刀路、身体旋转、脚步发力、对拼震荡、环境破坏同步发生。特效不能无缘无故乱炸。刀锋相撞时，黑色与冷白两套体系互相撕扯，伴随火花、透明冲击环和尘浪。可读的接触瞬间，特效不得吞没面部；不得变成巨大光炮或魔法球。

## 对拼时间线

`{{fight_beats}}`

节拍结构要求：每拍包含时间区间、穿越机运镜（须来自「镜头语言」声明的机位集合）、攻防动作（含起点/路径/接触点/结果）、该刀绑定的特效、环境反应，以及向下一拍延续的惯性/位置/朝向/压迫状态；时间区间连续覆盖 0-`{{duration_s}}` 秒，无空洞、无重叠。第 0 拍先继承首帧构图 `{{first_frame_hold_s}}` 秒，再进入第一圈环绕。

## 镜头语言

穿越机环绕语言：`{{camera_language}}`

摄影机运动：`{{camera_motion_rules}}`

固定镜头规则：穿越机环绕贯穿全片——高速贴身绕拍、低空环绕、侧后绕切、贴地掠过、人物之间穿梭、围绕对拼点高速盘旋。镜头快但不能乱飞：始终看清双方站位与攻防逻辑。更多从侧面、斜后、低机位、贴地、刀锋掠镜、人物之间穿越来拍，不要一直正面拍人脸。不要把镜头飞离决斗。撞击震动只极短，且方向与受力一致。允许适量运动模糊，但关键时刻面部、手、刀锋和接触点保持清晰。无游戏 UI、无作为贴图的速度线、无子弹时间、无长时间慢动作、不以鱼眼为默认造型。

## 声音设计

## 全局约束（渲染后必须保留在 Prompt 末尾）

- 第 0 秒首帧锁定生效：构图、服装、面容与左右站位继承 `{{first_frame_ref}}`，保持 `{{first_frame_hold_s}}` 秒。
- 双人物一致性锁定全程生效：不交换身份、不变脸、不改服装与体型、无第三名参战者。
- 场景不切换；布局与光影全片一致；破坏遵守 `{{environment_destruction}}`，并且有质量。
- 角色 A 保持压迫；角色 B 被压制但不败、不失风度；结尾不宣布击倒。
- 两套特效一眼可区分，并绑定刀路、身体、对拼与碎屑——无魔法球、无激光炮、无彩虹仙侠光。
- 每次进攻与格挡保留起点/路径/接触点/结果；穿越机环绕不得丢掉行动轴线。
- 镜头偏向侧面 / 斜后 / 低机位 / 贴地 / 刀锋掠镜 / 人物之间穿越；不要一直正面拍脸；不要乱飞。
- 无血条、准星、按钮提示、贴图速度线、冻结画面、子弹时间、长时间慢动作或任何文字 UI。
- 无血液、伤口特写、断肢。
- 时间线连续覆盖全片；结尾严格按 `{{ending_directive}}` 执行。

## 渲染后自检清单

1. 所有变量均已绑定，正文中不存在残留占位符。
2. `first_frame_ref` 来自已登记资产库，未编造引用。
3. 节拍时间区间连续覆盖 0-`{{duration_s}}` 秒；第 0 拍保持首帧构图 `{{first_frame_hold_s}}` 秒；每拍含起点/路径/接触点/结果、绑定特效、以及向下一拍的惯性延续。
4. 每拍运镜来自声明的穿越机集合；双方站位始终可读；没有一直正面拍脸。
5. A 与 B 的特效一眼可区分；特效绑定刀路与对拼，不是漂浮的光球或光炮。
6. 弧线能看出 A 在压、B 在高压下撑住；B 没有被击败，也没有失去风度。
7. 一致性锁定、同场景规则、破坏质量感、无 UI 禁令、无血腥禁令在全局约束与负面提示词中均已出现。

无法满足时：缺少必填变量、首帧参考图未登记、或时间线无法连续覆盖时，停止渲染并列出缺口，不得编造资产引用，也不得跳过首帧锁定、双色特效可区分性、或「压制但不击败」的收尾。
