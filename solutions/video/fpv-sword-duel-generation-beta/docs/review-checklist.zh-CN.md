# 评审清单：电影级穿越机刀战视频生成

渲染结果投递视频生成模型前，逐项核对：

## 变量与引用

- [ ] 无残留 `{{...}}` 占位符。
- [ ] `first_frame_ref` 来自已登记资产库。
- [ ] sensitive 输入（人物身份、场景、对拼时间线）未进入日志、事件或证据。

## 时序与结构

- [ ] 节拍连续覆盖 0-`duration_s`，无空洞、无重叠。
- [ ] 第 0 拍继承首帧构图，保持 `first_frame_hold_s` 秒后再环绕。
- [ ] 每拍攻防动作含起点、路径、接触点、结果；格挡改变或卸掉这一刀。
- [ ] 每拍写明绑定特效、环境反应、以及向下一拍延续的惯性/位置/朝向/压迫状态。
- [ ] 结构弧线可指认：A 持续压迫，B 被压但不败、不失风度，结尾胜负未分。

## 空间与镜头

- [ ] `scene_layout` 的开场站位（左 A / 右 B）与每拍位置一致；行动轴线清楚。
- [ ] 全程同一场景，无切场。
- [ ] 每拍运镜来自 `camera_language` 声明的穿越机集合：环绕、侧后、贴地、刀锋掠镜、人物之间穿越。
- [ ] 没有长时间正面拍脸，也没有无逻辑乱飞。
- [ ] 环境破坏遵守 `environment_destruction`，有质量感和方向。

## 特效与一致性

- [ ] A 黑狂侵略、B 冷净锐利，两套特效一眼可区分。
- [ ] 特效绑定刀路/转体/步法/对拼/破坏，无魔法球、激光炮、彩虹光。
- [ ] 双人物一致性锁定全文保留；无第三者、无身份互换敞口。
- [ ] 品质设定含真实摄影、PBR、布料/头发/尘土/石块/火花；无塑料 CG、动漫脸敞口。

## 无 UI、无血腥与投递

- [ ] 血条/准星/按钮/贴图速度线/子弹时间/文字 UI 禁令在镜头规则、全局约束、负面提示词中均已出现。
- [ ] 无血液、伤口特写、断肢。
- [ ] 声音设计与画面事件同步；音乐不盖刀锋接触声；无对白（除非显式声明）。
- [ ] 分辨率、画幅、帧率、时长与目标模型能力匹配。
