# 已知失败模式：电影级穿越机刀战视频生成

## 首帧漂移

- 症状：第 0 秒不是参考图构图，或左右角色对调、服装改色。
- 原因：`first_frame_ref` 未真正锁定，或第 0 拍立刻切到别的机位。
- 处理：第 0 拍先按 `first_frame_hold_s` 钉住首帧，再进入侧面低空环绕；左右身份写进一致性锁定。

## 穿越机乱飞、攻防读不清

- 症状：镜头高速盘旋后分不清谁在左、谁在进攻；人物频繁背对镜头。
- 原因：把「穿越机」理解成无锚点飞行，节拍未写站位延续。
- 处理：每拍写清双方位置与攻防角色；运镜只从声明集合里取；环绕必须能看见两人。

## 特效变成光炮

- 症状：出现魔法球、激光、彩虹光、巨大光波，或特效不跟刀走。
- 原因：模型把「特效重点」理解成仙侠大招。
- 处理：两套刀气写成墨风/真空斩纹等物质性刀路；`clash_vfx` 只写火花、透明冲击环、尘浪与旗幡撕裂；负面项封禁光炮。

## 双色特效糊成一套

- 症状：对拼时分不清哪一刀是 A、哪一刀是 B。
- 原因：两套 palette 写得太接近，或碰撞时只用一种爆炸色。
- 处理：A 固定黑墨/暗灰/黑羽，B 固定冷白/银白真空；碰撞写「黑与白互相撕扯」。

## 一人被秒杀或失风度

- 症状：B 倒地不起、被打飞出画、或表情崩坏；或 A 开局即终结。
- 原因：`fight_arc` 被理解成击倒结局。
- 处理：弧线强制「压制但不击败」；B 可以单膝着地、犁地后退，但必须重新稳住持刀。

## 破坏轻飘或切场

- 症状：石柱像纸片飘走，或突然换到另一处场景。
- 原因：破坏没有质量和方向，或模型自行换景找高潮。
- 处理：`environment_destruction` 写清可碎物件与碎裂边界；全局约束保留「全程同一废墟街巷」。

## 一直正面拍脸

- 症状：大量近景正脸对峙，失去速度与压迫感。
- 原因：默认肖像构图压过穿越机规则。
- 处理：默认机位改为侧面、斜后、低机位、贴地、刀锋掠镜；正面只允许极短确认身份。

## 敏感内容外泄

- 症状：人物身份、场景设计、对拼编排进入日志或测试证据。
- 原因：消费方未按 sensitivity 标记处理输入。
- 处理：sensitive 输入只进入渲染上下文；证据与日志只记录 digest、长度与状态。
