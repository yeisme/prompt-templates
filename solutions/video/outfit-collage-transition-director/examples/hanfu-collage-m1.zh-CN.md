# 实例：清冷汉服贵女五人拼贴 + M1/M2 卡点换装

本例展示 `outfit-collage-transition-director` 绑定为「汉服贵女」方向（对应上游参数推荐库方案 1）。无参考图，人物走默认补全规则。

## 变量绑定

| 变量 | 值 |
| --- | --- |
| `reference_image_ref` | （空） |
| `character_anchors` | （空 → 系统补全：原创中国成年女性，视觉年龄 22-28，自然东亚面部特征，气质清冷温婉） |
| `outfit_list` | 中央主造型：白色外披大袖袍 + 蓝色绣纹交领内层 + 浅蓝长裙；造型1：白色上衣 + 浅蓝百褶长裙 + 蓝色腰带；造型2：白色内搭 + 蓝色无袖马甲式长裙；造型3：浅蓝内裙 + 深蓝交领层次 + 白色外披长袖袍；造型4：浅灰紫外披 + 米白内搭 + 深蓝绣纹下裙 |
| `style_direction` | `清冷汉服贵女，同色系递进式汉服搭配` |
| `collage_layout` | （空 → 默认五人拼贴：中央偏右大人物，左上/右上/左中/左下小人物，右下留白） |
| `image_aspect` / `video_aspect` | `9:16` / `9:16` |
| `image_style` | （空 → 浅灰白无缝影棚、柔和漫射棚拍光、白色手绘虚线描边；主色系月白/浅蓝/银灰） |
| `video_duration_s` | `8` |
| `camera_rule` | （空 → 默认固定高机位俯拍 30-35°） |
| `transition_mechanism` | `M1`（统一一种，8 秒 4 次换装最稳；若追求古风表现力可改 `auto` → 映射 M1+M2 交替） |
| `beat_times` | （空 → 默认 1.25s / 2.95s / 4.40s / 6.55s） |
| `motion_tone` | `轻柔、含蓄、优雅` |
| `sound_design` | （空 → 无 BGM；点击、飞入、卡点完成、轻微衣料摩擦声） |
| `ending_action` | （空 → 结尾保留造型 4 展示） |

## 预期输出要点（评审对照）

1. 参数锁定结果：上述使用值逐条列出，`character_anchors`、`collage_layout`、`image_style`、`beat_times`、`camera_rule`、`sound_design`、`ending_action` 标记 `system-filled`，且人物节显式写「中国成年女性」。
2. 首帧图提示词：10 步构造顺序齐全；五套造型与人物锚点统一；小人物拓扑兼容中央人物。
3. 视频时间轴：5 段（初始 + 4 次 M1 换装），每段字段齐全，卡点与默认值一致。
4. 精简视频提示词：继承身份、布局、M1 消耗规则、固定高机位与音效节点。
5. 负面提示词：含第六人物、矩形缩略图、双重中央人物/残影、原位贴图保留、服装叠穿、多余手指、背景突变等条目。
