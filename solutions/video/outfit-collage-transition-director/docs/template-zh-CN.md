## 默认五人拼贴版式

除非 `collage_layout` 另有指定：中央偏右大人物占画面宽 60-65%；左上、右上（腰部以上紧凑）、左中、左下各一个小人物；右下留白。硬规则：正好 5 个人物且为同一角色；中央最大；小人物是沿真实身体轮廓裁切的完整抠像，各自独立白色虚线描边；中央人物不加虚线；禁止第六个人物；禁止矩形缩略图替代抠像。

## 首帧图片提示词构造顺序

1. 画幅 + 超写实商业摄影任务声明；2. 统一身份与外貌锚点；3. 人物数量与拼贴布局；4. 中央人物构图、姿态、主造型；5. 四个小人物的位置、构图、姿态与造型；6. 白色虚线贴纸效果；7. 背景、光线、镜头、皮肤、发丝、面料；8. 主色系与画面气质；9. 硬性限制；10. 负面提示词。

视频兼容优化：小人物不用极端扭曲姿势；头肩腰臂结构清晰；与中央人物身体拓扑兼容以便重合换装；袖摆裙摆披帛尽量完整；五个版本的脸、发型、发色、头饰、耳饰统一；中央初始姿态给后续动作留空间；背景简洁。

## 换装机制

`{{transition_mechanism}}` 指定时严格使用（M1-M12）；为 `auto` 时按映射选择并说明：拼贴互动 → M1 完整人物飞入重合；汉服大袖/披帛 → M2 袖摆遮镜，其次 M5 团扇遮挡；古风贵女 → M5；强拼贴设计 → M8 贴纸翻页；强节奏现代穿搭 → M10 步伐/手势卡点；分身/衣橱人格 → M9；东方幻想/神女 → M4 披帛、M6 花瓣云纹水墨或 M12 刺绣蔓延；高级清冷时尚 → M3 旋身接力或 M7 镜面同步。短视频不混用超过 2 种机制；8 秒 4 次换装最稳是统一一种，两种交替可接受，四次各不同不允许。

M1 默认动作链：指针点击目标小人物 → 复制完整人物抠像作为飞入副本 → 原位贴图立即移除并留空 → 副本斜向飞入中央并快速放大 → 虚线始终贴合副本轮廓 → 与中央人物头肩腰姿态重合 → 重合瞬间换装，副本与虚线同时消失 → 中央人物继续原动作。飞入的是完整人物副本，不是衣服或矩形卡片；原位不保留；重合后中央只剩一个人物，无重影。

## 视频时间轴构造

默认 8 秒、5 套造型 = 初始 + 4 次换装；默认换装完成点：1.25s / 2.95s / 4.40s / 6.55s。总时长变化且 `{{beat_times}}` 为空时按比例缩放并保留结尾造型展示时间；`{{beat_times}}` 给定则严格使用，不擅自平均化。

每段必须包含：时间范围、当前造型、人物动作、眼神/表情、换装触发、换装运动方向、换装完成时刻、换装后动作延续、发丝/袖摆/裙摆/流苏物理、必要音效。

## 动作连续性与衣料物理

每次换装前后保持：重心连续、旋转方向连续、手臂轨迹连续、头部朝向连续、眼神变化有因果、不因换衣重置姿势。飞入重合时必须先头肩腰姿势相合再换装。汉服、长裙、长袖、披帛、流苏：自然重力、转身轻微惯性延迟、停止后逐渐回落、换装瞬间物理连续、不僵硬漂浮、不穿模、不粘身。

## 镜头与声音规则

默认固定高机位：摄影机在人物前上方向下约 30-35°，近距离高机位俯拍，人物自然抬眼，头与上半身靠近镜头，裙摆向画面下方展开，全程固定，不推拉摇移变焦。仅当 `{{camera_rule}}` 明确要求时可用正面固定、轻微低机位、缓慢推近、轻微横移或半环绕。短时长中不同时叠加复杂运镜与复杂换装机制。

声音：默认无背景音乐；只加服务换装节点的音效——点击、飞入/滑动短促声、换装完成卡点声、轻微衣料摩擦；古风可加极轻丝带、扇面、花瓣掠过声。

## 强制一致性约束（输出中必须明确）

同一张脸；同一成年年龄感；同一国籍/族裔外观；同一肤色；同一发型发色；同一头饰耳饰；同一身材比例；只改变穿搭不重做人物；换装前后动作连续；已使用的小人物贴图原位不保留；不出现第六人物；不出现矩形缩略图；不出现双重中央人物/残影；不服装叠穿；不错误肢体/多余手指/身体融合；不头部裁切；不背景突变；不无故镜头移动。
