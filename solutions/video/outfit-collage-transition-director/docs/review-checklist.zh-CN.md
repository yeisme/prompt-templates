# 评审清单：穿搭拼贴首帧 + 卡点换装视频导演

渲染结果投递前，逐项核对：

## 变量与锁定

- [ ] 无残留 `{{...}}` 占位符。
- [ ] `reference_image_ref` 若填写，来自已登记资产库，未编造。
- [ ] 用户显式输入逐字进入输出第 1 节；系统补全项全部标记 `system-filled`。
- [ ] sensitive 输入（人物锚点、造型清单）未进入日志、事件或证据。

## 人物与一致性

- [ ] 默认人物规则合规：无参考图且无锚点时才用「原创中国成年女性」，并在各输出段落显式声明；未用服饰/文化符号代替族裔外观。
- [ ] 五个版本人物的脸、发型、发色、头饰、耳饰统一；只改变穿搭。
- [ ] 强制一致性约束完整出现在负面约束节。

## 版式与图片

- [ ] 正好 5 个人物，中央最大，右下留白（或 `collage_layout` 声明的新逻辑）。
- [ ] 小人物是完整身体抠像、各自独立白色虚线描边；无矩形缩略图、无第六人。
- [ ] 首帧图提示词按 10 步构造顺序齐全；满足视频兼容优化（拓扑兼容、姿势不极端、袖摆裙摆完整）。

## 视频时间轴

- [ ] 每段字段齐全（时间范围/造型/动作/表情/触发/方向/完成时刻/延续/布料物理/音效）。
- [ ] 卡点时间：用户给定则逐字一致，否则为默认点的等比例缩放；结尾保留最终造型展示时间。
- [ ] 换装机制 ≤ 2 种；M1 遵循「复制飞入、原位消耗、重合后单人物」规则。
- [ ] 动作连续性与衣料物理要求写入各段。

## 镜头、声音与投递

- [ ] 镜头规则与机制复杂度未叠加（短时长固定机位优先）。
- [ ] 默认无 BGM；音效只服务换装节点。
- [ ] 无文字/Logo/水印禁令出现在输出中。
- [ ] 生成的图片/视频提示词为英文（投递模型用），变量内容语言不限。
