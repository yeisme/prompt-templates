# Profile：Cinematic Live Action

`profile_id`：`cinematic_live_action`。maturity：`exploratory`；readiness：`candidate`；rights：仅使用消费 Owner 已投影且确认可用的角色、地点、道具、声音与交付权利，不推定肖像、音乐、商标或演员声音权利。

共享状态语义保持为：source projection → active bindings → semantic proposal → Owner candidate/review；本 profile 不创建 canonical ref、digest、acceptance 或 provider run。

风险优先级：身份稳定、表演可观察性、手与道具接触、重心/布料/重量物理、光源逻辑、口型与空间声。证据最低要求：face/wardrobe/location/prop 的安全 binding 摘要、SceneGEO、镜头时长窗、可见 evidence summary；多人物还需轴线与 screen direction。

建议时长：生成单段以 4–8 秒为默认可审查窗口；复杂动作拆为更短覆盖，最终时长由 Scaena/Sonora Owner 决定。readiness 仅在 identity、GEO、first frame、音画责任和低风险替代均有证据时可建议 prototype；不得宣称 production-ready 或 final。

特有 QC：转头不重构身份、衣物/伤痕状态连续、接触前后物理一致、非说话者反应不泄露信息、稳定双人 coverage 可替换高风险 hero shot。
