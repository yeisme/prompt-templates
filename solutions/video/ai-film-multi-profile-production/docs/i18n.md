- 约束等价：en sidecar 的 input type、required、enum、min/max length、sensitivity 与 zh-CN sidecar 完全一致；`profile_id` enum 与各 role `output_schema_version` enum 不变，schema ref 指向同一份 `contracts/schemas/*.schema.json`。
- 结构等价：七个 en 正文保留七层结构（owner boundary → profile contract → accepted source projection → active reference bindings → task delta → output schema and findings → self-check without chain of thought）；稳定 failure code、输出字段清单与禁止输出边界逐条保留。
