# 实例：雨夜高架检修站近身格斗（30 秒 ACT 跟随）

本例展示 `realistic-fight-scene-generation` 绑定为一条「深夜暴雨地铁站厅格斗」Prompt。无 Provider 横幅（`provider_banner` 留空）。

## 变量绑定

| 变量 | 值 |
| --- | --- |
| `footage_style` | `写实电影级实拍质感` |
| `duration_s` / `resolution` / `aspect_ratio` / `frame_rate` | `30` / `1080p` / `16:9` / `24fps` |
| `scenario_summary` | `深夜暴雨的停运高架地铁检修站内，主角与敌人的现代近身格斗` |
| `style_reference` | `现代硬派武术电影气质（迅猛、贴身、攻防转换极快、真实接触感）+ ACT 动作游戏第三人称战斗镜头；不照搬参照作品的人物、场景与具体镜头` |
| `protagonist_identity` / `antagonist_identity` | 严格继承两组参考图的面部、年龄、发型、体型、身高比例、服装、鞋子、配饰与整体气质 |
| `protagonist_ref` / `antagonist_ref` | `@image1`（主角）/ `@image2`（敌人），投递时槽位顺序一致 |
| `character_dynamics` | `主角冷静、精准、动作幅度小，善于格挡后立即反击；敌人力量更大、进攻性更强，擅长连续压迫和贴身撞击` |
| `dual_consistency_lock` | `全程不得交换身份，不得变脸、改变服装颜色、改变体型或生成第三名参战者` |
| `scene_desc` | `深夜暴雨的停运高架地铁检修站：狭长矩形站厅，湿滑深灰防滑地砖与浅水洼；左侧金属检票闸机与关闭卷帘门，右侧半透明钢化玻璃护栏外是高架轨道、雨幕、车灯与模糊城市建筑；中段三根黄黑警示条混凝土立柱，尽头短楼梯通往废弃站台` |
| `scene_layout` | `开场主角在站厅中段偏左、背近闸机面朝右前方，敌人在右前方约三米、背对玻璃护栏；前半段向站厅深处移动，中段绕第二根立柱，后半段反向压回闸机区；除环绕镜头明确换位外敌人始终在主角前方，行动轴线清楚` |
| `lighting_palette` | `冷白灯管主光（两盏接触不良偶尔闪烁），红色维修警示灯提供少量轮廓光；斜吹雨水、潮湿薄雾与地面积水反射参与画面；冷蓝灰主色` |
| `action_principles` | `现代实战拳法、肘击、膝撞、低位踢击、近身控制、擒拿拆解和短距离摔法` |
| `fight_arc` | `敌人抢攻→主角反击→绕柱追击→主角失势→危险拆解→夺回主动→闸机摔投→最终反制；主角经历一次明显失势（头撞眩晕）和一次危险化解（肘击内圈拆解），靠判断与重心控制夺回主动` |
| `environment_interaction` | `立柱、闸机、玻璃护栏、积水参与战斗：重拳砸柱只产生闷响与灰尘（柱不碎），肩膀撞玻璃只震颤不破碎，闸机挡板被撞开弯曲但不脱离，摔投落水水花真实扩散` |
| `camera_follow_spec` | `主角肩后/腰后/侧后第三人称 ACT 跟随为主（约一米距离、腰部至肩部高度、轻微广角）；关键格挡和重击短暂切入侧面中景或近景` |
| `cut_rules` | `隐形切镜只用：人物身体遮挡、立柱擦镜、快速摇镜、撞击震动、动作匹配；切镜后必须延续动作惯性、人物位置、身体朝向、伤势和攻击方向；禁止瞬移、换位错误、突然恢复站姿、无理由越轴` |
| `camera_motion_rules` | `摄影机快速但有真实重量，不漂浮/瞬移/疯狂旋转/持续乱抖；撞击震动极短低幅度且方向与受力一致；适量运动模糊，但面部、手脚和接触点在关键时刻保持清晰` |
| `realism_rules` | `超写实皮肤、肌肉牵拉、衣料褶皱、湿润头发、汗水与雨水反射；真实金属、混凝土、玻璃与湿地砖材质；高对比保留暗部细节，高光不过曝` |
| `audio_design` | `严格同步的现场声：雨击顶棚、远处雷声、脚踩积水、湿地摩擦、衣料摆动、急促呼吸、拳掌击肉、前臂格挡、肘膝碰撞、身体撞柱、玻璃震颤、闸机金属回响；无对白；音乐仅极克制低频脉冲` |
| `ending_directive` | `主角惯性前半步后稳住重心、双手保持防守，不庆祝不摆造型；镜头缓慢移到主角右侧以其肩膀为前景，焦点落在半跪喘息的敌人身上；红色警示灯闪烁一次，远处雷声；最后一帧保持双方互相锁定的危险状态` |
| `final_feel` | `清晰的动作结构：30 秒全程高强度无废秒，刺激而不混乱，凶狠但遵守人体力学，摄影机始终以主角为核心` |
| `negative_prompts` | 见模板默认负面项（身份互换/物理崩坏/特效/UI 四类全保留） |

## 格斗时间线（`fight_beats` 压缩版）

```text
[0-4s 敌人抢攻] 机位：主角右后方约一米肩高 ACT 跟随。敌人踩水洼右直拳攻面（起点：右前方三米；接触：拳锋擦过脸侧）；主角左偏头+左手拍腕+右前臂架左摆拳；敌人肩撞逼退主角半步；敌人抬膝攻腹，主角双肘压膝+右脚切入支撑腿外侧。切点：无（开场连续）。延续：主角退半步稳住，敌人在正前方。
[4-8s 第一次反击] 机位：主角手臂遮挡切至两人右侧平行低中景。主角控臂短拳击肋（敌上身左缩）；敌左肘横击太阳穴，主角右臂格挡震动；主角左肘击胸+右脚低扫小腿；敌抓住主角推向第一根立柱，主角左掌撑柱卸力绕柱，敌重拳擦肩砸柱（闷响+灰尘，柱不碎）。切点：手臂遮挡。延续：绕柱躲避动势。
[8-13s 绕柱追击] 机位：紧贴主角背后绕柱跟随。立柱遮满画面完成隐形切镜；出遮挡后主角在柱右侧，敌人左侧追出，向楼梯方向纵深移动。敌左右直拳压迫，主角后撤格挡；敌第三击改右腿中段踢，真实命中主角护臂，主角踉跄撞上玻璃护栏（震颤不碎+雨夜灯光拖影）；敌压肩肘击面部，主角低头避过+控臂反压，敌强行抽臂以额头撞主角眉骨（主角头部后移、额角轻微擦伤、目光短暂失焦）。切点：立柱擦镜。延续：主角带伤+眩晕。
[13-17s 主角失势] 机位：侧面近景（头撞瞬间+飞散雨水+眩晕）随即拉回全身中景，无长慢动作。敌抓上身拽回站厅中央+右腿绊摔；主角倾斜中右脚踩稳+左手勾敌后颈贴身角力；摄影机环绕约九十度明确换位（敌左主角右，主角背后为第二根立柱与闸机方向）；敌将主角压在立柱边缘，肩撞+短膝击（主角大腿与前臂挡住仍弯腰）；敌抬右肘准备下砸后背。切点：撞击震动+环绕换位。延续：换位后轴线明确，主角处于被压状态。
[17-22s 危险拆解] 敌右肘下砸；主角向其身体内侧贴近使肘尖落空，托肘控腕以肩为支点旋转破肩线；机位半环绕跟随，立柱/闸机/警示灯提供空间参照。敌顺势转身左拳反击；主角放开低头闪过，起身右肩撞胸推离立柱；左直拳逼防→右拳臂下击腹→左肘短击锁骨（三次分别清楚，不多臂）。敌退两步脚跟撞闸机底座，右腿横扫；主角前贴压缩距离，左臂承受大腿近端，右手环腰+左脚切支撑脚外侧（低机位交代重心控制）。切点：半环绕。延续：主角夺回主动，敌重心被控。
[22-26s 环境摔投] 主角转髋斜前方发力，将敌摔向闸机：敌肩背先撞闸机侧面（挡板撞开+刺耳金属声），落湿地水花扩散（真实重量，不飘不翻多圈）。机位沿落地方向快速俯冲，触地转略高斜俯视。主角跨过撞开的挡板追击；敌翻身右脚蹬膝（主角侧移避开），借蹬腿翻滚起身，未站直挥右摆拳；主角内侧进入，左臂贴臂+右掌推下颌（敌后仰卸力），敌左拳击中主角侧腹（主角明显收腹），主角右膝短撞敌大腿前侧。延续：双方呼吸加重、衣服湿污，动作不疲软。
[26-30s 高潮反制] 机位回主角左后方约一米 ACT 跟随；背景为撞开的闸机、闪烁顶灯与红色警示灯。敌最后前冲：左拳虚晃+右肘横扫真攻；主角右掌压下虚招，前踏入内圈左前臂架上臂使肘尖脑后掠过；抓后颈+右脚勾前脚踝+肩部前下施压。敌后倒抓主角衣服试图同倒；主角松开后颈左转身出抓握，右肘极短距离击胸偏肩+左掌推开上胸。敌后撞已打开的闸机挡板（挡板进一步弯曲），半跪落地一手撑地一手防守，无昏迷无飞出画面。按结尾指令收束：主角稳住防守，镜头移至主角右侧肩前，焦点落半跪敌人，红灯闪一次+远雷，双方互相锁定。
```

## 渲染与投递

- 投递时 `@image1`=主角参考图、`@image2`=敌人参考图，槽位顺序与引用一致。
- 自检重点：七拍与结构弧线一一对应；每次接触都有四要素；13-17s 环绕换位是唯一轴线变化；损毁边界（柱不碎/玻璃不碎/挡板可弯）在环境参与与负面项中呼应。
