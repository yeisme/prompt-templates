# 评审清单：写实近身格斗视频生成

渲染结果投递视频生成模型前，逐项核对：

## 变量与引用

- [ ] 无残留 `{{...}}` 占位符。
- [ ] `protagonist_ref` 与 `antagonist_ref` 来自已登记资产库，且指向不同资产。
- [ ] sensitive 输入（人物身份、场景、格斗时间线）未进入日志、事件或证据。

## 时序与结构

- [ ] 节拍连续覆盖 0-`duration_s`，无空洞、无重叠；无开场对视/摆造型/绕圈试探（除非弧线显式要求）。
- [ ] 每拍攻防动作含起点、路径、接触点、结果；格挡改变攻击方向。
- [ ] 每拍写明向下一拍延续的惯性/位置/朝向/伤势。
- [ ] 结构弧线各阶段可指认；主角的失势与危险化解各至少一次。

## 空间与镜头

- [ ] `scene_layout` 的开场站位、移动路径与每拍位置一致；行动轴线清楚。
- [ ] 切镜手段全部来自隐形切点白名单；无硬切、黑屏、越轴（除环绕展示的换位）。
- [ ] 每拍机位来自 `camera_follow_spec` 声明的集合。
- [ ] 环境互动遵守 `environment_interaction` 的损毁边界。

## 一致性与写实

- [ ] 双人物一致性锁定全文保留；无第三者、无身份互换敞口。
- [ ] 写实约束含皮肤/肌肉/衣料/材质条目；无 CG 感、蜡像皮、噪点敞口。
- [ ] 双方都有有效攻防；无「主角全程无伤」或「敌人只挨打」敞口。

## 无 UI 与投递

- [ ] 血条/准星/按钮/速度线/子弹时间/文字 UI 禁令在摄影规则、全局约束、负面提示词中均已出现。
- [ ] 声音设计与画面事件同步；音乐仅限低频脉冲、不盖格斗音效；无对白（除非显式声明）。
- [ ] 分辨率、画幅、帧率、时长与目标模型能力匹配。
