# 写实近身格斗视频生成 Prompt（双人物 ACT 跟随）——中文阅读版

> 本文档是 `prompts/main.en.md` 的中文阅读版，仅供人工审阅，**未注册为模板 locale，不进入 catalog 编译**。渲染与投递一律以英文模板为准；变量名与英文模板一一对应。

`{{provider_banner}}`

本模板渲染后可直接投递视频生成模型，用于生成「双人物写实近身格斗」视频：双参考图身份锁定、攻防物理可审查、行动轴线与空间连续性、ACT 第三人称跟随镜头。消费方在渲染前完成全部变量绑定；渲染结果是最终 Prompt 正文，不经过二次改写。

与家族内其他模板的边界：特效/技能/大招镜头用 `ai-drama-shot-video-generation`；写实 vlog 三个流见各自 usage。本模板专攻无特效、强物理、双人格斗场景。

## 使用方式

1. 按 companion contract 填写全部 required 变量；`protagonist_ref` 与 `antagonist_ref` 为必填双参考图引用（支持 `@uuid` 与 `@image1`/`@image2` 位置引用），两者不得指向同一资产。
2. 可选：`provider_banner` 保留投递平台标识行，留空则省略。
3. `fight_beats` 按「格斗时间线」结构编写，连续覆盖 0-`{{duration_s}}` 秒。
4. 渲染后先人工核对「自检清单」，再投递视频生成模型。

## 双人物与一致性锁定

主角：`{{protagonist_identity}}`，严格参考 `{{protagonist_ref}}`。敌人：`{{antagonist_identity}}`，严格参考 `{{antagonist_ref}}`。

格斗风格对比：`{{character_dynamics}}`。

一致性锁定（全片不可放宽）：`{{dual_consistency_lock}}`

固定规则：全程不得交换两人身份，不得变脸、改年龄、改发型、改体型、改身高比例、改服装颜色、改鞋子配饰；不得生成第三名参战者。

## 场景与空间连续性

`{{scene_desc}}`

空间布局与行动轴线：`{{scene_layout}}`

光影与材质：`{{lighting_palette}}`

固定规则：场景空间在所有镜头中保持一致，门、立柱、装置与护栏的位置不得随切镜改变；除非通过环绕镜头明确展示换位，否则双方始终保持清楚的行动轴线，摄影机不得无理由越轴。

## 动作原则

`{{action_principles}}`

固定物理规则：每次进攻必须呈现起点、运行路径、接触点和结果；格挡必须真正改变攻击方向；受击者的头部、肩膀、躯干、脚步和重心按力量方向产生反馈；禁止隔空挥拳、拳脚穿透身体、无接触自行后退、无故旋转、连续空翻、悬浮与夸张飞行；动作可以快，但关键接触点必须清楚，不得用混乱残影掩盖动作。

结构弧线：`{{fight_arc}}`

环境参与：`{{environment_interaction}}`

固定规则：双方都必须有有效攻防——禁止主角全程无伤碾压，也禁止敌人静止挨打；主角的失势与化解必须来自判断、重心控制或环境利用，不得凭空翻盘。

## 格斗时间线

`{{fight_beats}}`

节拍结构要求：每拍包含时间区间、机位（须来自「摄影规则」声明的机位集合）、攻防动作（含起点/路径/接触点/结果）、隐形切点（身体遮挡、立柱擦镜、快速摇镜、撞击震动、动作匹配）、以及向下一拍延续的惯性/位置/朝向/伤势状态；时间区间连续覆盖 0-`{{duration_s}}` 秒，无空洞、无重叠。

## 摄影规则

跟随机位：`{{camera_follow_spec}}`

隐形切镜与连续性：`{{cut_rules}}`

摄影机运动：`{{camera_motion_rules}}`

固定规则：摄影机快速但有真实重量，不得漂浮、瞬移、疯狂旋转或持续无规则抖动；撞击震动只极短低幅度且方向与受力方向一致；允许适量运动模糊，但人物面部、手脚和接触点在关键时刻保持清晰；ACT 感来自主角中心构图、第三人称跟随、空间推进和及时的动作反馈，不来自任何游戏 UI。

## 写实约束

`{{realism_rules}}`

默认写实约束（未被 `realism_rules` 覆盖时并入）：超写实皮肤与肌肉牵拉、衣料褶皱、湿发、汗水与雨水反射；真实金属、混凝土、玻璃与湿地材质；高对比但保留暗部细节，高光不过曝；禁止蜡像皮肤、塑料 CG 质感、噪点颗粒、锐化白边与压缩色块。

## 声音设计

`{{audio_design}}`

固定规则：现场声音严格同步画面事件；音乐只允许极克制的低频脉冲，不得盖过格斗音效；无对白（除非 `audio_design` 显式声明）。

## 结尾与整体气质

结尾指令：`{{ending_directive}}`。最终气质：`{{final_feel}}`。

## 全局约束（渲染后必须保留在 Prompt 末尾）

- 双人物一致性锁定全程生效：不交换身份、不变脸、不改服装与体型、无第三名参战者。
- 切镜必须延续上一镜的动作惯性、人物位置、身体朝向、伤势和攻击方向；禁止瞬移、换位错误、突然恢复站姿、无理由越轴。
- 场景空间布局与光影在全片一致；环境物件参与战斗时遵守 `{{environment_interaction}}` 的损毁边界。
- 每次进攻与格挡遵守固定物理规则；双方都有有效攻防，主角经历弧线要求的失势与化解。
- 无血条、准星、按钮提示、速度线、冻结画面、子弹时间、长时间慢动作、鱼眼与任何文字 UI。
- 时间线连续覆盖全片；结尾严格按 `{{ending_directive}}` 执行。

## 负面提示词

`{{negative_prompts}}`

默认负面项（未被 `negative_prompts` 覆盖时并入）：身份互换，面孔漂移，服装变化，身体比例突变，多余人物，复制人物，多手多脚，关节反折，身体穿透，人物粘连；隔空受击，动作没有惯性，敌人静止等待，无故滑行，瞬移，悬浮，轻功，气功，能量特效，夸张冲击波，墙体爆炸；主角全程无伤碾压，敌人只会挨打；无意义空镜，英雄登场，长时间对视，重复招式，结尾突然黑屏；鱼眼，长时间慢动作，子弹时间，冻结画面，速度线，血条，准星，按钮提示，文字 UI；蜡像皮肤，塑料 CG 质感，噪点，锐化白边，压缩色块。

## 渲染后自检清单

1. 所有变量均已绑定，正文中不存在残留占位符。
2. 两个参考图引用均来自已登记资产库且互不相同，未编造引用。
3. 节拍时间区间连续覆盖 0-`{{duration_s}}` 秒；每拍含起点/路径/接触点/结果与向下一拍的惯性延续说明。
4. 每拍机位来自摄影规则声明的集合；切镜手段都在隐形切点白名单内。
5. 结构弧线各阶段（抢攻/反击/追击/失势/拆解/夺回/终结）在节拍中可指认。
6. 一致性锁定、空间连续性、物理规则、无 UI 禁令在全局约束与负面提示词中均已出现。

无法满足时：缺少必填变量、参考图未登记或两个引用相同、时间线无法连续覆盖时，停止渲染并列出缺口，不得编造资产引用或跳过一致性锁定与物理规则。
