# 评审清单：AI 短剧镜头级视频生成

渲染结果投递视频生成模型前，逐项核对：

## 变量与引用

- [ ] 无残留 `{{...}}` 占位符。
- [ ] 所有 `@` 资产引用来自已登记资产库，未编造。
- [ ] sensitive 输入（创作内容）未进入日志、事件、证据或结构化输出。

## 时序与结构

- [ ] 分镜时间区间连续覆盖 0-`duration_s`，无空洞、无重叠。
- [ ] 每镜动作数 ≤ `max_actions_per_second`。
- [ ] 蓄力期镜头未混入收尾期动作（落地、收剑、定格站立）。
- [ ] 敌方在爆发期之前未提前全灭；最后一秒完成清场并定格。
- [ ] 冲击帧等级与镜头节奏匹配：常规绞杀一级、蓄力压缩二级、终极爆发三级。

## 约束一致性

- [ ] `charge_phase_rule` 与 `release_phase_rule` 不互相矛盾，分镜动作可明确归属阶段。
- [ ] 安全协议（`gore_protocol`）全文保留，敌方死亡表现符合协议。
- [ ] 负面提示词与全局约束两节完整保留在渲染结果末尾。
- [ ] `wardrobe_anchors` 与 `scene_anchors` 在全局约束和分镜中均有呼应。

## 画质与风格

- [ ] `quality_profile`、`effect_mix`、`color_grading` 与实际投递模型的能力匹配（画幅、时长上限）。
- [ ] 运镜转场只使用白名单方式：Whip Pan、前景遮挡、爆闪过场、盲区欺骗、CRANE。
