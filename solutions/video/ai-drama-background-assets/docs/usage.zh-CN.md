# 空场景背景资产使用说明

`clean-background-plate-v1` 用于生成完整、不透明的零人物背景板。它与人物资产属于不同任务、不同 run 和不同 review artifact；基础资产阶段不得合成。

必须提供地点锚点、机位、时间/天气、光线、画幅和人物活动预留区。模板固定 `subject_count=0`，并禁止人物、肢体、人影、倒影、剪影、雕像、人体模特、人物照片和海报等一切人形痕迹。

人工审阅重点：无人和无人形痕迹、无人物倒影或投影、空间结构完整、活动区可用、画布完全不透明。Eikona accept 不等于 Scaena frozen 或 production accepted。
