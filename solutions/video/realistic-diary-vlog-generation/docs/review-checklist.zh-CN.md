# 评审清单：写实日记 Vlog 视频生成

渲染结果投递视频生成模型前，逐项核对：

## 变量与引用

- [ ] 无残留 `{{...}}` 占位符。
- [ ] `character_ref` 若填写，来自已登记资产库，未编造。
- [ ] sensitive 输入（梗概、人物、时间线、台词脚本）未进入日志、事件或证据。

## 时序与结构

- [ ] 节拍连续覆盖 0-`duration_s`，无空洞、无重叠。
- [ ] 每拍 1-3 个可观察动作；允许自然停顿与空镜呼吸。
- [ ] 每拍标注地点与声学空间；机位来自 `camera_formats` 声明的集合。
- [ ] 每个事件有可拍到的触发源，无内心描写。

## 台词与唇形

- [ ] 每句台词绑定到存在的口播拍；无台词的拍标注 none。
- [ ] 台词文本与 `dialogue_script` 逐字一致，未被改写或翻译。
- [ ] 口播拍占比符合「偶尔自述」（建议不超过节拍数的一半）。
- [ ] 口播拍均要求画面可见人物说话；唇形同步要求出现在写实约束中。
- [ ] `dialogue_language` 与台词文本语言一致。

## 一致性、声学与写实

- [ ] `consistency_lock` 全文保留；服装逻辑链条完整，每次换装都有日记事件支撑。
- [ ] 声学空间随地点变化且 room tone 全程存在。
- [ ] 光线只来自场景内普通光源；无 glam 打光敞口。

## 无文字与投递

- [ ] 无字幕/标题/UI/Logo/水印禁令出现在台词规则、全局约束、负面提示词三处。
- [ ] 摄像机不入境（含镜面反射）已声明；自拍拍有可信手持距离与角度。
- [ ] 分辨率、画幅、时长与目标模型能力匹配；变量内容语言与骨架 locale 独立，按消费方需求填值。
