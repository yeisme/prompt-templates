# 写实日记 Vlog 视频生成 Prompt（出镜口播一日记录）——中文阅读版

> 本文档是 `prompts/main.en.md` 的中文阅读版，仅供人工审阅，**未注册为模板 locale，不进入 catalog 编译**。渲染与投递一律以英文模板为准；变量名与英文模板一一对应。

本模板渲染后可直接投递视频生成模型，用于生成「主人公亲自对镜头说话」的写实日记 Vlog：出镜台词、唇形同步、空间声学连续性。消费方在渲染前完成全部变量绑定；渲染结果是最终 Prompt 正文，不经过二次改写。

与家族内其他模板的边界：无旁白纯环境音抓拍用 `realistic-vlog-shot-generation`；画外 VO 自述用 `realistic-docu-vlog-generation`；人物对镜头直接说话、需要唇形同步的日记记录用本模板。

## 使用方式

1. 按 companion contract 填写全部 required 变量；有人物资产时填写 `character_ref`（支持 `@uuid` 与 `@image1` 位置引用）。
2. 可选：`provider_banner` 保留投递平台标识行（如 `Made with Seedance 2.5`），留空则省略。
3. `story_beats` 按「日记时间线」结构编写；`dialogue_script` 的每句台词必须绑定到一个节拍。
4. 渲染后先人工核对「自检清单」，再投递视频生成模型。

## 日记时间线

`{{story_beats}}`

节拍结构要求：每拍包含时间区间、地点与声学空间（如卧室/街道/排练室）、拍摄格式（须来自 `camera_formats` 声明的集合）、1-3 个可观察动作、台词绑定键（无台词的拍标注 none）；时间区间连续覆盖 0-`{{duration_s}}` 秒，无空洞、无重叠；允许自然停顿与空镜呼吸，但事件必须有可拍到的触发源。

## 出镜台词

`{{dialogue_script}}`

语言：`{{dialogue_language}}`。台词规则：每句通过绑定键落到对应节拍；台词只以自然口语人声存在于音轨，绝不生成字幕、标题或任何屏幕文字；台词文本逐字保留，不得改写或翻译；口播拍必须画面可见人物说话且唇形与台词可信对应；台词是偶尔的亲密自述，不对每拍都安排口播。

## 声音设计

现场声与声学空间：`{{ambience_design}}`。声音禁止项：`{{audio_exclusions}}`。

声学空间必须随地点真实变化（卧室的近距安静、街道的开阔混响、排练室的反射声等），房间底噪（room tone）全程存在。

## 写实约束

`{{realism_rules}}`

默认写实约束（未被 `realism_rules` 覆盖时并入）：准确解剖与自然身体力学，可信的唇形同步，自然眨眼、呼吸与表情，真实的头发与织物运动，正确的光照与阴影；禁止面部漂移、人物复制、塑料皮肤、手部畸形、悬浮道具与环境形变。

## 结尾与整体气质

结尾指令：`{{ending_directive}}`。最终气质：`{{final_feel}}`。

## 全局约束（渲染后必须保留在 Prompt 末尾）

- 一致性锁定全程生效：面部、发型、体型、性格气质在任何镜头不得漂移；换装只按服装逻辑发生。
- 无字幕、标题、翻译、Logo、水印、UI 元素或任何屏幕文字；台词只以自然口语声音存在。
- 摄像机绝不入境，不出现镜面/反光穿帮；自拍拍必须是可信的手持距离与角度。
- 无商业摆拍、无 glam 广告打光；光线始终来自场景内的普通光源。
- 所有事件必须有可拍到的触发源；禁止凭空出现的物体与特效。
- 时间线连续覆盖全片；声学空间随地点切换；结尾严格按 `{{ending_directive}}` 执行。

## 负面提示词

`{{negative_prompts}}`

默认负面项（未被 `negative_prompts` 覆盖时并入）：商业摆拍，glamour 广告打光，精致商业质感，稳定器/无人机/不可能机位；面部漂移，人物复制，塑料皮肤，手部畸形，悬浮道具，环境形变，服装无逻辑变化；唇形与台词不匹配，机械播音腔；字幕，标题，屏幕文字，Logo，水印，UI 元素；摄像机入境，镜面穿帮；凭空出现的物体，无触发源事件。

## 渲染后自检清单

1. 所有变量均已绑定，正文中不存在残留占位符。
2. `character_ref` 若填写，必须来自消费方已登记的资产库，未编造引用。
3. 节拍时间区间连续覆盖 0-`{{duration_s}}` 秒；每拍含地点与声学空间，机位来自 `camera_formats` 声明的集合。
4. 每句台词绑定到存在的口播拍；台词文本与 `dialogue_script` 逐字一致；口播拍占比符合「偶尔自述」。
5. 服装逻辑链条完整：每次换装都有日记事件支撑。
6. 一致性锁定、写实约束（含唇形同步）、声音与拍摄禁止项完整保留；无字幕禁令在台词规则、全局约束、负面提示词三处均已出现。

无法满足时：缺少必填变量、台词无法绑定节拍或时间线无法连续覆盖时，停止渲染并列出缺口，不得编造资产引用、改写台词文本或跳过一致性锁定。
