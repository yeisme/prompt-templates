# 实例：日系偶像的一日私密日记（60 秒口播 Vlog）

本例展示 `realistic-diary-vlog-generation` 绑定为一条「日系偶像私下一日」Prompt。无 Provider 横幅（`provider_banner` 留空）。

## 变量绑定

| 变量 | 值 |
| --- | --- |
| `footage_style` | `photorealistic personal diary vlog` |
| `duration_s` / `resolution` / `aspect_ratio` | `60` / `1080p` / `16:9` |
| `scenario_summary` | `一位日系偶像风格的年轻表演者，记录私密的一天：从清晨房间到排练室再到夜间道别` |
| `subject_identity` | `同一位年轻表演者；保持确切面部、发型与性格气质（开朗、爱玩、不设防）` |
| `wardrobe_and_accessories` | `居家服（宽松T恤）→ 外出服（休闲外套+牛仔裤）→ 排练服（运动套装）；每次换装由出门/到店/排练事件支撑` |
| `consistency_lock` | `全片保持完全一致的面部、发型、服装逻辑与性格气质` |
| `character_ref` | 有参考图时填 `@image1` 等位置引用 |
| `camera_formats` | `手持自拍 + 亲密朋友手持跟拍 + 自然固定机位` |
| `camera_imperfections` | `手持手机构图、小幅失焦、普通室内光、自然停顿、俏皮即兴反应` |
| `camera_exclusions` | `无商业摆拍、glamour 广告打光、稳定器与不可能的机位` |
| `dialogue_language` | `自然日语口语` |
| `ambience_design` | `干净的现场原生声：卧室近距安静、街道开阔混响、便利店/咖啡馆嘈杂底色、排练室反射声；room tone 全程存在，声学空间随地点真实变化` |
| `audio_exclusions` | `无字幕、屏幕文字、Logo、水印；无罐头音效` |
| `realism_rules` | `准确解剖与自然身体力学，可信唇形同步，自然眨眼呼吸与表情，真实头发与织物运动；无面部漂移、人物复制、塑料皮肤、手部畸形、悬浮道具` |
| `ending_directive` | `安静的夜间道别，录制自然结束` |
| `final_feel` | `一段真实的私人影像日记：亲密、俏皮、不完美，像一个普通却值得记住的日子` |
| `negative_prompts` | `商业摆拍，glamour 打光，面部漂移，人物复制，塑料皮肤，手部畸形，悬浮道具，Logo，字幕，屏幕文字；唇形不匹配，播音腔；摄像机入境，镜面穿帮` |

## 日记时间线（`story_beats`）

```text
[0-7s] 卧室（近距安静）｜固定机位自拍视角｜对镜头日语早安问候，揉眼睛笑。台词：d1
[7-14s] 卧室/厨房｜朋友手持跟拍｜悠闲早餐与准备细节：烤面包、涂果酱、随手扎头发。台词：none
[14-20s] 客厅地板｜固定机位｜和蓬松的猫玩耍，被猫无视后对着镜头做鬼脸。台词：d2
[20-26s] 街道→便利店（开阔→嘈杂）｜手持自拍｜走进便利店买饭团，对镜头展示。台词：none
[26-32s] 街道/车站｜手持移动｜地点间移动，风与城市声，偶尔回头看镜头。台词：none
[32-44s] 排练室（反射声）｜固定机位+手持｜排练准备：拉伸、戴耳返；短暂表演片段。台词：none
[44-52s] 后台角落｜手持自拍｜不设防的休息：坐在地上喝水、揉肩膀、小声吐槽累。台词：d3
[52-60s] 卧室夜（近距安静）｜固定机位｜安静的日语夜间道别，挥手，录制自然结束。台词：d4
```

## 出镜台词（`dialogue_script`）

```text
d1（0-7s）：おはよう！今日は私の一日を撮ってみます。
d2（14-20s）：ねえ、見て…また無視された。
d3（44-52s）：ちょっと疲れたけど、楽しかった。
d4（52-60s）：今日もありがとう。おやすみ。
```

## 渲染与投递

- 台词为日语原句，`dialogue_language=自然日语口语`；模板 locale 与台词语言独立，投递英文模型用 `main.en.md` 渲染即可。
- 自检重点：d1-d4 全部落在口播拍；口播拍 4/8，符合「偶尔自述」；声学空间按地点切换；无字幕禁令三节齐出。
