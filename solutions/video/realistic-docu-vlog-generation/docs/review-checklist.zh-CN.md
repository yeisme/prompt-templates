# 评审清单：写实纪实 Vlog 视频生成

渲染结果投递视频生成模型前，逐项核对：

## 变量与引用

- [ ] 无残留 `{{...}}` 占位符。
- [ ] `character_ref` 若填写，来自已登记资产库，未编造。
- [ ] sensitive 输入（梗概、人物、时间线、VO 脚本）未进入日志、事件或证据。

## 时序与结构

- [ ] 节拍连续覆盖 0-`duration_s`，无空洞、无重叠。
- [ ] 每拍 1-3 个可观察动作；蒙太奇拍列出 3-5 个快切画面。
- [ ] 每拍机位来自 `camera_formats` 声明的集合，未发明新机位。
- [ ] 每个事件有可拍到的触发源，无内心描写。

## VO 与音乐

- [ ] 每句 VO 绑定到存在的节拍；无旁白的拍标注 none。
- [ ] VO 文本与 `voiceover_script` 逐字一致，未被改写或扩写。
- [ ] `vo_tone` 要求保留（私密自述感，非播音腔）。
- [ ] `music_arc` 终点与 `ending_directive` 协调，无「提前高潮」或「结尾无音乐收束」矛盾。

## 一致性与写实

- [ ] `consistency_lock` 全文保留；节拍中无未锁定的外观变化。
- [ ] 写实约束含解剖、物理、光影、材质条目；无 CGI/塑料皮肤/美颜 Filter 风险敞口。

## 无文字与投递

- [ ] 无字幕/标题/UI/Logo/水印禁令出现在 VO 规则、全局约束、负面提示词三处。
- [ ] 摄像机不入境（含镜面反射）已声明。
- [ ] 分辨率、画幅、时长与目标模型能力匹配；变量内容语言与骨架 locale 独立，按消费方需求填值。
