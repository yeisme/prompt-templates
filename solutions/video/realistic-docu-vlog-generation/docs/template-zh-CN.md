# 写实纪实 Vlog 视频生成 Prompt（VO 旁白一日记录）——中文阅读版

> 本文档是 `prompts/main.en.md` 的中文阅读版，仅供人工审阅，**未注册为模板 locale，不进入 catalog 编译**。渲染与投递一律以英文模板为准；变量名与英文模板一一对应。

`{{provider_banner}}`

本模板渲染后可直接投递视频生成模型，用于生成「主人公自述一日记录」气质的写实纪实 Vlog：逐拍旁白（VO）、音乐弧线、混合机位。消费方在渲染前完成全部变量绑定；渲染结果是最终 Prompt 正文，不经过二次改写。

## 使用方式

1. 按 companion contract 填写全部 required 变量；有人物资产时填写 `character_ref`（支持 `@uuid` 与 `@image1` 位置引用）。
2. 可选：`provider_banner` 保留投递平台标识行（如 `Made with Seedance 2.5`），留空则省略。
3. `story_beats` 按「故事时间线」结构编写，`voiceover_script` 的每句 VO 必须绑定到一个节拍。
4. 渲染后先人工核对「自检清单」，再投递视频生成模型。

## 全局约束（渲染后必须保留在 Prompt 末尾）

- 一致性锁定全程生效：身份、面部、发型、体型与服装在任何镜头不得漂移。
- 无字幕、标题、翻译、Logo、水印、UI 元素或任何屏幕文字；对白与旁白只以自然声音存在。
- 摄像机绝不入境，不出现镜像穿帮。
- 所有事件必须有可拍到的触发源；禁止凭空出现的物体与特效。
- 时间线连续覆盖全片；音乐弧线与结尾指令（`{{ending_directive}}`）协调一致。
- 拍摄禁止项与声音禁止项全程生效。

## 渲染后自检清单

1. 所有变量均已绑定，正文中不存在残留占位符。
2. `character_ref` 若填写，必须来自消费方已登记的资产库，未编造引用。
3. 节拍时间区间连续覆盖 0-`{{duration_s}}` 秒；每拍机位来自 `camera_formats` 声明的集合。
4. 每句 VO 都绑定到存在的节拍；VO 文本与 `voiceover_script` 逐字一致。
5. 一致性锁定、写实约束、声音与拍摄禁止项完整保留。
6. 音乐弧线终点与结尾指令不冲突；无字幕类禁令在全局约束与负面提示词中均已出现。

无法满足时：缺少必填变量、VO 无法绑定节拍或时间线无法连续覆盖时，停止渲染并列出缺口，不得编造资产引用、改写 VO 文本或跳过一致性锁定。
