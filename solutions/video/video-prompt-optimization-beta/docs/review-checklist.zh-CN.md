# video-prompt-optimization-beta 评审清单

评审一次编译产出（或模板本身改版）时逐项检查。

## 结构完整

- [ ] 正文从【全局设定】起，五行齐：画质/画面纯净度/音频/其他/基调。
- [ ] 有素材时【角色设定】【场景资产】按 @图片N（名称）映射；【场景与空间说明】逐人钉方位、视线、间距。
- [ ] 每镜六层齐：画面内容/光影/声音设计/台词/风格锚点/衔接；最后一镜改「结束状态」。
- [ ] 全部镜头后有全局一致性收束段。
- [ ] 纯文本协议：【】〖〗•，无 Markdown 语法。

## 方法论正确

- [ ] 全文零否定句；被排除物名词（现代器物词、火焰/静音等）未出现，由陈设与目标状态占位。
- [ ] 无台词镜台词栏恰好「无」两字，声音设计点名 1–2 个真实声源；无「嘴唇闭合」防御句（画外音例外）。
- [ ] 反射只写受光与高光；易合体对（容器×火源、镜面×人影）分句独立。
- [ ] 抽象情绪词已翻成呼吸/眼神/嘴角/肢体指令；关键动作有起点→过程→终点。
- [ ] 180° 轴线与屏幕侧锁定；跨镜终点与下一镜起点逐项一致。
- [ ] 风格锚点每镜完整重写（含焦段+光圈），无「同镜1」省略；光影/声音同环境才引用复用。
- [ ] 挂图 ≤4、色温光影统一；指代语法与声明的 `media_reference_syntax` 完全一致；目标平台互斥规则已核实遵守。
- [ ] 运镜用相对量级词，无绝对数值（时间标注除外）。

## 时长与台词

- [ ] 需求时长 = ⌈台词字数÷4⌉ + 静默秒数 已按目标模型上限核算；超限走拆分策略且改方案经用户同意。
- [ ] 逐句语速与全局语速一致（无「全局 5.5 字/秒、逐句 4.4」式自相矛盾）。
- [ ] 台词逐字保留（含标点、语气词）；发音注记只在表演指导括号内；专有词「字源+拼音+声调」且出现次数正确。
- [ ] 时间戳与截止按软约束表述，未承诺绝对秒点。

## 边界与越权

- [ ] 未自行添加台词、角色、情节、情绪走向；未把提交参数（含 negative 通道）写进正文。
- [ ] 「优化重跑」语义保持完整 prompt 单条原生生成；分段/后期/独立配音未出现（除非用户明确授权）。
- [ ] 输出只有正文块 + 至多几条正文外准备说明；未夹带合规检查清单腔调。

## 判定口径

三张卡与自检清单是降低概率风险的工具，不是判通过/不通过的红线。命中「高危条件」不等于必崩：先出片、看片，连续 2–3 次同类抽卡失败才谈改方案。评审先看调度（机位给谁、顶点敢不敢怼特写、建立镜有没有交代后果），再对卡取舍。
