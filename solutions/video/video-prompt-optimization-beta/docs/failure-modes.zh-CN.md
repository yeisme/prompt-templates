# video-prompt-optimization-beta 已知失败模式

按「先归因、再修」的顺序排列。三张卡命中是概率风险，不是死刑判决；最终裁判是出片。

| 症状 | 归因 | 修复 | 不要做 |
| --- | --- | --- | --- |
| 正文出现「不要X」句式 | 否定卡违规 | 删掉否定句，改写目标状态；被排除物名词全文清零；有独立 negative 通道的平台经提交层写入通道 | 在合规声明里复述被排除物名词 |
| 人一不说话就没声音（数字静音观感） | 声音卡：写了「死寂/极低底噪」或未点声源 | 删静音类词；逐镜点名 1–2 个连续具体声源 | 写「禁止静音」这类否定句 |
| 静默镜人物被配上口型 | 未声明画外音场景 | 仅画外音/接电话场景写「嘴唇闭合、口型不动」 | 给所有静默镜都加防御句 |
| 茶盏/容器长明火、器物合体、反射物实体化 | 器物卡：相邻共现或视觉先验击穿文字 | 分句独立写；改形制/换参考图/挪光源 | 堆「不得合体/绝不燃烧」类否定词 |
| 角色长发变短发、场景风格压不住 | 参考图视觉先验强于文字 | 换参考图或改文字设定，二选一，先改来源 | 堆文字声明赌覆盖 |
| 台词被改写/删减/合并 | 违反逐字保留 | 原样恢复；超长走加时长→跨镜→拆单元链路 | 先斩后奏删台词 |
| 同词连续发音失败 | 模型执行波动（非写法失败） | 保持 prompt 稳定继续抽卡；向用户说明命中率边界 | 无限叠加同义发音说明 |
| 逐镜时间没落在标注秒点 | 时间戳是软约束 | 看整段节拍是否连贯；归为模型自决 | 以「第N秒必须发生X」为验收标准 |
| 抽卡一次不理想就改方案 | 把波动当写法失败 | 连续 2–3 次同类失败才谈改方案 | 静默换成分段/后期/独立配音 |
| 单元结尾人物莫名起身走动 | 段尾未显式收住 | 最后一镜写「结束状态：...」+ 全局收束段 | 依赖下一单元开头去纠正 |
| 全局语速与逐句语速矛盾 | 时长核算缺失 | 逐句 字数÷窗口 与全局 总字数÷总窗口 复核一致 | 只算总片长不算发声窗口 |
| 素材指代与目标平台语法不符（@图片N/@imageN/UUID 混用） | media_reference_syntax 未声明或不一致 | 统一替换为声明的语法；无正文指代语法的平台改用位置描述 | 各平台语法混写 |
| 换高分辨率想救内容问题 | 内容层失败与分辨率无关 | 回到提示词约束、素材与能力边界判断 | 反复升分辨率重抽 |
| 正文混入分辨率/比例/时长参数/negative 通道内容 | 协议越界 | 移交提交层；正文只保留画面内容与时间标注 | 在正文里写「竖屏 9:16」或排除词清单 |
| 多单元拼接穿帮（服装/道具/声源不一致） | 设定档案缺失或逐镜私加新物 | 建/补档案；逐镜不引入档案外新器物、声源、饰物 | 靠事后剪辑修穿帮 |
