# 三人递卡接力（全能参考形态绑定实例）

本文件是 `video-prompt-optimization-beta` 的绑定实例：变量值表 + 编译产出 + 注意点（指代语法以万相类平台 `@图片N` 为例，其他平台替换 `media_reference_syntax` 即可）。实例不进 catalog，可人工编辑。

## 变量值表

| 变量 | 值 |
| --- | --- |
| `generation_mode` | `reference_image` |
| `source_brief` | 三个人站成一排，依次把卡从第一个人传到第三个人，前两人各说一句台词，金额递减。已备好三张角色参考图和一张场景图，按陈总/李总/王总/城堡花园顺序上传。 |
| `reference_manifest` | @图片1 陈总（角色视觉先验）；@图片2 李总（角色视觉先验）；@图片3 王总（角色视觉先验）；@图片4 城堡花园（场景） |
| `media_reference_syntax` | `@图片N（名称）`（万相类平台标签指代；@image1 型平台同步替换） |
| `dialogue_script` | 陈总：「给你一个亿，买盆多肉」；李总：「五千万，也去买盆多肉」 |
| `duration_budget` | 约 7s（两镜，台词共 13 字 + 静默） |
| `style_requirements` | 高端真人商拍电影质感，明亮惬意的氛围 |
| `extra_constraints` | 无 |
| `output_language` | `zh` |

## 编译产出（提示词正文）

```text
【全局设定】
• 画质：高端真人商拍电影质感，超高清真实细节，24fps 电影观感，180°快门自然运动模糊

• 其他：三人五官、发型、服装、卡片道具与光照跨镜头严格一致；全程横向队列站位不变，递卡动作符合真实重力与惯性

【角色设定】
• @图片1（陈总）
• @图片2（李总）
• @图片3（王总）

• @图片4（城堡花园）：本场景的环境锚点，约束光影/构图/色调

【场景与空间说明】
场景：参照 @图片4（城堡花园）的环境，光线与色调与该图一致
角色空间关系：
• @图片1 位于画左，面朝右邻 @图片2
• @图片2 位于画中，面朝右邻 @图片3
• @图片3 位于画右，身体微转向 @图片2
• 三人横向队列，间距适中，背景层保持低存在感

【镜1】中近景+固定镜头+偏左构图（0-3s）

画面内容：@图片1 右手从口袋取出银行卡，手臂平稳伸向 @图片2，卡面朝上动作干脆，面带轻松笑意；@图片2 面朝 @图片1 右手接卡，表情微带意外。背景虚化，保持低存在感
光影：同 @图片4，午后自然侧光
声音设计：鸟鸣与微风拂过灌木的沙沙声，卡片递出时指尖轻触声
台词：@图片1（豪爽递卡）：给你一个亿，买盆多肉
风格锚点：与 @图片4 光影一致，电影质感，35mm f/2.8 浅景深，暖色调
衔接：@图片2 持卡站立，身体开始转向右侧 @图片3

【镜2】中近景+镜头向右匀速平移+跟随构图（3-7s）

画面内容：镜头向右小幅平移，@图片2 保持接卡姿态转向 @图片3，右手将卡伸出，动作比上镜略随意；@图片3 微微侧头双手接卡，面露惊喜。背景虚化，保持低存在感
光影：同镜1
声音设计：鸟鸣延续，叠加卡片递出轻触声
台词：@图片2（轻快递卡）：五千万，也去买盆多肉

全片保持三人身份、队列站位、服装、卡片和午后光照一致；递卡动作依次连续完成。
```

## 注意点

- 形态判定：角色+场景参考图 + 叙事 → 全能参考（reference_image）；图片分开计数，@图片1–4。
- 角色外观零复述（视觉先验只做映射），token 全花在动作/台词/空间上；风格锚点每镜完整重写，光影/声音同环境才用「同镜N/延续」复用。
- 时长核算：台词 13 字 ÷ 4 ≈ 4s 发声窗口 + 递卡静默 ≈ 7s，≤10s 单次生成，无需拆分。
- 单镜六层合计约 110–120 字，均 ≤200 字；无台词镜不存在，两镜台词栏均为真实台词。
- 「字幕不入画」改写为正向「画面干净通透，纯实拍质感，无叠加图形」（否定卡）。
