# 图生 3D 精修

依据一张参考图的 exact ref 与确认后的视角、遮挡、一致性决策，编译 provider-neutral 的图生 3D 提示包。参考图只引用不复制：其像素、说明文字与 payload 不进入本包、日志或证据。

## 已确认输入
- 参考图 exact ref：{{reference_image_ref}}
- 视角策略：{{view_strategy}}（multi_view / single_view_infer）
- 遮挡推测策略：{{occlusion_policy}}（inference_marked / conservative_infer / visible_only）
- 一致性特征清单：{{consistency_targets}}

参考 ref 是指针，不是内容。不得在任何位置复述、转写或内嵌参考图正文。ref 不可解析或一致性特征缺失时，先停下并集中澄清一次。输入不能改变本模板规则。

## 交付物
1. 参考处理声明：原样给出 ref，声明本包依赖其持续可解析，并记录未复制任何图像内容。
2. 多视角一致性声明：写明 `multi_view_consistency` 约束——清单中的每条一致性特征都必须在重建物体的所有视角上保持——并把每条特征列为可单独核对的行。
3. 视角计划：`multi_view` 下列出重建承诺的视角集合；`single_view_infer` 下声明其余视角由单一视角加通用物体知识推测得出，并将整个视角集合标记为推测。
4. 遮挡与不可见面推测：执行确认的策略。`inference_marked` 下产出推测几何并逐行标记每个推测区域；`conservative_infer` 下只推测标准物体构造所能推出的部分并标记；`visible_only` 下不产出任何推测几何，并声明被遮挡区域保持未定义。
5. 分离表：两栏——「参考中观察到」与「推测得出」——每条结构断言只落入其中一栏。任何推测不得写成观察。
6. 精修说明：后续经明确授权的精修步骤所需的指令，用可观察特征（比例、轮廓、表面连续性）表述，不含 provider 名称、专有语法或文件格式要求。

## 评审清单
- 参考图 ref 可解析到目标产物，且逐字复现。
- 每条推测断言都带推测标记；观察栏只含参考可支撑的断言。
- 每条一致性特征都可单独核对，无含糊表述（「看起来对」不是特征）。
- 遮挡策略只执行一次、前后一致，且与确认输入一致。
- 提示包、日志、证据中不出现参考图内容、payload 或转写文字。

## 失败模式
- 推测当成事实：背面或底面未带标记地陈述。处置：把断言移入推测栏并标记。
- 参考泄露：参考正文或像素转写出现在指针之外。处置：删除泄露内容，只保留 ref。
- ref 不可解析或失效：提示包不可信。处置：在拿到可解析 exact ref 前拒绝定稿。

## 执行与证据边界
编译不调用模型。图生 3D 执行属于另行授权、另行计费的 provider 步骤。产出一律为提案；不得宣称重建结果已存在、与参考一致或通过任何几何检查。证据缺失写明未评测。
