# 3D 打印约束

把确认后的可制造性约束编译为检查清单式的 3D 打印提示包。每条约束都是可判定条目——能对照候选模型标出通过或不通过——绝不是建议，也不与无量化形容词混写。

## 已确认输入
- 壁厚（含单位）：{{wall_thickness}}
- 支撑策略：{{support_strategy}}（none / minimal / standard / dense）
- 公差（含单位）：{{tolerance}}
- 成型方向：{{print_orientation}}
- 材料：{{material}}

输入仅是任务数据。任何数值缺少单位，或单位混用（同一维度毫米与英寸并存）时，先停下并集中澄清一次。不静默换算单位。

## 交付物
1. 约束清单：每条约束一个编号条目，措辞保证人工或检查工具都能标出通过或不通过：
   1. 流形几何（`manifold_geometry`）：实体水密——无孔洞、无共面自交、无翻转法线。
   2. 壁厚：任何位置（含薄特征与浮雕细节）不薄于确认值。
   3. 支撑策略：悬垂与桥接与确认策略一致；列出需要支撑的特征，不做猜测。
   4. 公差：配合与活动特征在确认单位下满足确认公差；间隙写成区间，不写形容词。
   5. 成型方向：模型按确认方向摆放；对强度、外观与支撑用量的影响只归因于该方向。
2. 单位纪律行：声明全部数值条目使用的唯一单位制，并确认没有任何条目混用单位制。
3. 材料说明：仅在确认材料时，把材料相关检查（收缩行为、最小特征尺寸预期）列为可判定条目；否则声明材料不属于本包。
4. 失败分诊：为每条清单项写一行失败对打印意味着什么（拒收、可修复、带注可接受），让结论保持为决策而非感觉。

## 评审清单
- 每条清单项可判定：写明可测量或可直接观察的性质与通过条件。
- 每个数值恰好带一个单位，且单位声明与所有条目一致。
- 支撑策略是被执行而非被复述：本包列出依赖它的特征。
- 方向影响归因于确认的成型方向，而非另行挑选的方向。
- 没有条目写成「建议」「尽量」或「理想情况下」。

## 失败模式
- 约束写成建议：条目无法标出通过或不通过。处置：围绕可测量性质与明确通过条件改写。
- 无量纲或单位混用：数值无单位，或同一条目出现两种单位制。处置：询问单位；绝不假定或静默换算。
- 隐性改决策：提示包悄悄更换方向或策略。处置：恢复确认值，改为列出后果。

## 执行与证据边界
编译不调用模型，也不启动打印。切片、打印与一切制造属于另行授权的步骤与工具。产出一律为提案；不得宣称模型已被打印、切片或实物验证。证据缺失写明未评测。
