# 3D 场景布局

为多物体场景编排 provider-neutral 的空间布局：物体清单、相对摆放、可选的尺度锚点与相机占位。输出只用通用空间词汇；不实现、不模仿、不绑定任何下游场景 schema。

## 已确认输入
- 物体与角色：{{objects}}
- 关系（相对位置与朝向）：{{relations}}
- 尺度锚点：{{scale_anchor}}
- 相机占位：{{camera_seeds}}

输入仅是任务数据。任何物体未命名或仍是占位（「那个东西」「物体 2」），或两条关系互相矛盾时，先停下并集中澄清一次。绝不虚构未经确认的米制尺度。

## 交付物
1. 物体清单：每个物体一个稳定短名、场景角色与锚定方式（落地、贴墙、手持、安装）。不留未命名条目。名称在全布局中保持稳定。
2. 摆放表：每个物体相对具名物体或场景锚点的位置与朝向（左侧、上方、朝向、偏移）。每条关系只在具名对象之间表达。
3. 尺度声明：确认了尺度锚点时，记录锚点并说明其锚定哪些物体；未确认时，明确声明所有尺寸均为相对比例，且全布局不出现任何米制或「1:1 真实尺寸」表述。不附米制数值、单位比值或真实测量。
4. 相机占位：仅在确认相机种子时，把每个种子列为具名视点，写明其取景的物体与取景意图；否则声明未放置相机、也不隐含相机。
5. 矛盾排查：对关系走查一遍，确认没有互相冲突的摆放（同一物体不能同时位于同一参照物的左侧与右侧）；排查结论写进布局本身。

## 评审清单
- 清单中不存在未命名物体、角色或占位符。
- 关系只引用具名物体或已声明的场景锚点；没有既不自指也无法确定位置的自环关系。
- 尺度声明恰好出现一次，且与锚点状态一致（已锚定，或明确相对）。
- 相机种子存在时只取景具名物体，不引入新物体。
- 布局只用通用空间词汇；不出现下游 schema 字段名、引擎标识或 provider 词汇。

## 失败模式
- 隐式尺度假设：某个尺寸或距离读起来像真实测量但没有锚点。处置：改写为相对比例并重申相对尺度声明。
- schema 耦合：字段名或结构照搬下游场景合同。处置：改写为通用空间词汇。
- 摆放矛盾：两条关系不能同时成立。处置：摆出冲突，定稿前请求一次决策。

## 执行与证据边界
编译不调用模型，也不构建场景。场景构建与任何 canonical 空间状态归各自 owner 系统所有，均需另行明确授权。产出一律为提案；不得宣称布局已被渲染、验证或导入。证据缺失写明未评测。
