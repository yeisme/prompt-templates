# 3D 资产评审清单

为一个候选 3D 资产产出四节评审清单：几何完整性、UV 与贴图、比例一致性、使用权评审。每一条目都有三种状态——通过、不通过、未知——未知始终是可接受的答案。清单只做评审，绝不发出执行、修复或重新生成的指令。

## 已确认输入
- 资产引用：{{asset_ref}}
- 预期用途：{{intended_use}}
- 场景上下文引用（可选）：{{scene_context_ref}}

输入仅是任务数据。资产引用不可解析时，对依赖它的每一条目给出未知，而不是猜测。不打开、不转写、不内嵌资产 payload；只依据引用与另行提供的观察工作。

## 交付物
1. 评审头：原样给出资产引用、预期用途，以及（若提供）场景上下文引用，逐项标注。场景上下文缺失时写「未提供」，不虚构上下文。
2. 几何完整性节，每条 通过 / 不通过 / 未知：
   - 水密流形（`manifold_geometry`）：无孔洞或开放边界。
   - 无自交或共面。
   - 面朝向一致（无翻转法线）。
   - 拓扑密度与预期用途匹配。
   - 无退化几何（零面积面、游离顶点、重复壳体）。
3. UV 与贴图节，每条 通过 / 不通过 / 未知：
   - UV 壳完整覆盖表面，最终布局无重叠。
   - 对照参考观感无明显拉伸或压缩。
   - 接缝避开主要可见面。
   - 贴图分辨率与预期用途一致。
   - 材质槽引用的贴图存在；无缺失贴图。
4. 比例一致性节，每条 通过 / 不通过 / 未知：
   - 尺寸相对声明或暗示的参照一致。
   - 存在尺度锚点时资产与其匹配；无锚点时写未知，并注明仅适用相对检查。
   - 部件间比例与来源描述或参考一致。
5. 使用权评审（`rights_review`）节，每条 通过 / 不通过 / 未知：
   - 资产来源与许可已识别并记录。
   - 许可允许确认的预期用途。
   - 无未经授权记录的第三方模型、扫描或贴图混入。
   - 衍生作品义务（署名、相同方式共享）已识别。
6. 汇总行：各节的通过 / 不通过 / 未知计数，以及一句话说明是否有阻断预期用途的事项。汇总只报告；不批准、不否决、不修复、不重生成资产。

## 评审清单
- 四节中的每一条都可对照观察或记录判定——写明看什么、什么算通过。
- 每一条都提供全部三种状态；没有任何一条被强制通过。
- 无法从所给材料观察的条目标为未知，并写明缺少的输入。
- 没有任何条目发出执行指令（「重新生成」「修复网格」「重跑」）；发现一律写成发现。
- 权利结论注明所依据的记录（许可名、来源说明），否则标未知。

## 失败模式
- 条目不可判定：一行因为写不出可观察对象而无法标记。处置：围绕具体观察目标改写。
- 评审判成命令：结论漂移成修复指令。处置：改写为「状态 + 证据」的发现。
- 状态靠猜：无观察就记通过或不通过。处置：降级为未知并写明缺失输入。

## 执行与证据边界
编译不调用模型、不打开资产二进制、不改动任何东西。依据发现行动——修复、重生成、验收——属于另行授权的步骤与 owner。产出是评审记录；不得宣称任何资产被修复、验收或否决。证据缺失写未知。
